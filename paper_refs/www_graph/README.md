# WWW Graph References

These papers are selected for their relevance to graph representation, recovery,
global structure, scalability, and Web graph modeling.

1. `WWW2023_GNN_without_Propagation.pdf`
   Graph Neural Networks without Propagation, WWW 2023. Useful for motivating
   alternatives to repeated local propagation and for studying a compact graph
   representation route.

2. `WWW2023_Robust_Graph_Representation_Local_Corruption_Recovery.pdf`
   Robust Graph Representation Learning for Local Corruption Recovery, WWW
   2023. Useful for recovery-oriented motivation, graph autoencoding, corruption
   handling, and experimental presentation.

3. `WWW2024_Graph_Skeleton.pdf`
   Graph-Skeleton: ~1% Nodes are Sufficient to Represent Billion-Scale Graph,
   WWW 2024. Useful for Web-scale graph compression, preserving structural roles,
   and explaining why a compact representation must retain global connectivity.

4. `WWW2025_Graph_Sequential_Alignment.pdf`
   Graph-Sequential Alignment and Uniformity: Toward Enhanced Recommendation
   Systems, WWW Companion 2025. Useful for shared embedding interfaces,
   multi-objective training, and recommendation-oriented result writing.

5. `WWW2024_Graph_Principal_Flow_Network.pdf`
   Graph Principal Flow Network for Conditional Graph Generation, WWW 2024.
   Useful for coarse-to-fine graph generation, spectral structure, and
   generation-focused ablation and evaluation design.

## WWW 2026

6. `WWW2026_RLSTG_Riemannian_Liquid_ST_GNN.pdf`
   Riemannian Liquid Spatio-Temporal Graph Network. Useful for non-Euclidean
   geometry, continuous-time graph dynamics, and representation of structured
   systems beyond flat vector spaces.

7. `WWW2026_RAG_GFM.pdf`
   RAG-GFM: Overcoming In-Memory Bottlenecks in Graph Foundation Models via
   Retrieval-Augmented Generation. Useful for discussing lossy parameter
   compression, external structural memory, and cross-domain graph modeling.

8. `WWW2026_ScaleGNN.pdf`
   ScaleGNN: Towards Scalable Graph Neural Networks via Adaptive High-order
   Neighboring Feature Fusion. Useful for high-order structure, over-smoothing,
   selective neighbor retention, and Web-scale efficiency.

9. `WWW2026_ReaLM.pdf`
   ReaLM: Residual Quantization Bridges Knowledge Graph Embeddings and Large
   Language Models. Useful for quantized graph embeddings and interfaces between
   structural representations and language models.

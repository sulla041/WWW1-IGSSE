\section{Conclusion}
\label{sec:conclusion}

\method{} maps an attributed graph to a node-aligned point set by combining
content coordinates with adjacency-conditioned structural deviations.  Joint
content and relation recovery trains this point set as an empirical approximate
equivalence class, while prediction and rule-guided growth read the resulting
representation.  Across Web, program, circuit, timing, molecular, and social
graph tasks, this embedding-recovery route provides a common basis for
downstream modeling and graph generation.

\section{IGSSE}
\label{sec:method}

\method{} is organized around the modeling route
\begin{equation}
 G=(V,E,\mathbf X)\ \xrightarrow{\operatorname{Enc}_{\theta}}
 \Hset=\{\mathbf h_i\}_{i=1}^{n}\ \xrightarrow{R_{\phi}}\ \widehat Y .
 \label{eq:ghy}
\end{equation}
Here $G$ is an attributed graph, $\Hset$ is a point set whose rows correspond to nodes, and
$\widehat Y$ denotes the downstream prediction.  The central design choice is to
make $\Hset$ both a prediction object and a recoverable representative of $G$.
The algorithm therefore has three parts.  First, the embedding stage constructs a
point set by combining an original content coordinate $\mathbf h_{o,i}$ with a
structural deviation $\mathbf o_i$.  Second, graph recovery decodes content and
relations from $\Hset$, making recoverability the guarantee of approximate
equivalence.  Third, downstream readers operate directly on $\Hset$ for node
prediction, graph prediction, and autoregressive graph modeling.

\subsection{Representation object and notation}
\label{sec:setup}
Let $G=(V,E,\mathbf X)$ be an attributed graph with adjacency target
$\mathbf A$ and $n$ nodes.  The task label $y$ can be a node label, graph label,
or continuous target.  \method{} produces
$\Hset\in\mathbb R^{n\times d}$, where row $i$ remains associated with node
$i$.  This row correspondence is essential: a content decoder reads node content
from one point, while a relation decoder reads graph relations from point pairs.

The recovery target is $T(G)=(\mathbf A,\mathbf C)$, where
$\mathbf C=\operatorname{sg}(\operatorname{Enc}_{X}(\mathbf X))$ and
$\operatorname{sg}$ stops gradients.  A configuration may instead recover a
standardized raw feature target.  In either case, labels are excluded from
recovery.  We use $\Hset_{\mathrm{dec}}$ for the final state verified by the
content and relation decoders, and $\Hset_{\mathrm{task}}$ for the final state
or jump-concatenated reader input.

\paragraph{Core path correspondence.}
Figure~\ref{fig:algorithm-core} summarizes the computation graph.  The algorithm
first forms an original content coordinate $\mathbf h_{o,i}$.  Trainable
projections then produce queries, keys, and values, from which the global
attention field constructs contextual source states.  The observed adjacency
selects which source states can be written to each target node, and their
weighted sum forms the structural deviation $\mathbf o_i$.  The final point
$\mathbf h_i$ is obtained by fusing $\mathbf h_{o,i}$ and $\mathbf o_i$.  Later
layers repeat the same path with the previous point state as the new original
coordinate.

\subsection{Embedding as a point set}
\label{sec:fsde}
At layer $\ell$, let $\mathbf h_{o,i}^{(\ell)}$ denote the original coordinate
that will receive the structural write.  At the first layer,
\begin{equation}
  \mathbf h_{o,i}^{(0)}=\operatorname{Enc}_X(\mathbf x_i).
  \label{eq:baseline}
\end{equation}
For later layers, $\mathbf h_{o,i}^{(\ell)}=\mathbf h_i^{(\ell-1)}$.  The
attribute encoder only reads $\mathbf X$, so it supplies a content reference
before graph-conditioned writing.

\paragraph{Original coordinate $\mathbf h_{o,i}$.}
The original coordinate is the content carrier of each point.  Query, key, and
value vectors are obtained from $\mathbf h_{o,i}^{(\ell)}$ through trainable
projections.  Their pairwise attention scores create a global attention field,
and the weighted values form contextual source states $\mathbf u_s$.  The
adjacency defines the write set
$N_A(i)=\{s:(s,i)\in E\}\cup\{i\}$ for each target $i$.

\paragraph{Structural deviation $\mathbf o_i$.}
For each target, a softmax over $N_A(i)$ gives $\alpha_{si}^{(m)}$.  The
projected multihead write defines the structural deviation:
\begin{equation}
 \mathbf o_i^{(\ell)}=\mathbf W_O\Vert_m\sum_{s\in N_A(i)}\alpha_{si}^{(m)}\mathbf u_s^{(m)}.
 \label{eq:deviation}
\end{equation}
This term summarizes relation-selected global source states and encodes the
structural correction to the original content coordinate.  During training, a
noise network may perturb relation scores according to training progress; during
evaluation, clean relation scores are used.

\paragraph{Fusion into $\mathbf h_i$.}
The final point is produced by fusing the original coordinate and structural
deviation with a normalized feedforward update $\Phi$:
\begin{equation}
 \mathbf h_i^{(\ell)}=\Phi\!\left(\mathbf h_{o,i}^{(\ell)}+\operatorname{Dropout}(\mathbf o_i^{(\ell)})\right).
 \label{eq:fusion}
\end{equation}
After $L$ layers, $\Hset_{\mathrm{dec}}=\mathbf H^{(L)}$ is used for recovery.
Node tasks may use this final state or a jump concatenation of layer states.

\subsection{Approximate equivalence of the point set}
\label{sec:recovery}
Recovery uses $\Hset$ as the modeling object.  The relation decoder reads two
points and recovers whether a graph relation exists; the content decoder reads
one point and recovers its content target.  Together, the two decoders make the
learned point set an approximate equivalence class of the graph under the chosen
recovery targets.

The relation decoder projects final point rows to head specific queries and
keys, scores their scaled inner product, symmetrizes undirected relations, and
applies a learned scale and bias.  For a candidate pair $(i,j)$,
\begin{equation}
 s_{ij}=\rho\,\operatorname{Mean}_{m,\leftrightarrow}\!\left(\frac{(\overline{\mathbf q}_i^{(m)})^\top\overline{\mathbf k}_j^{(m)}}{\sqrt{d_h}}\right)+\beta,\quad \widehat A_{ij}=\sigma(s_{ij}).
 \label{eq:pairattn}
\end{equation}
The link loss applies binary cross entropy to $s_{ij}$ and $A_{ij}$.  The
content decoder is
\begin{equation}
 \widehat{\mathbf C}=D_C(\Hset_{\mathrm{dec}}).
 \label{eq:feat}
\end{equation}
The content loss measures mean squared error between $\widehat{\mathbf C}$ and
$\mathbf C$.  Relation recovery evaluates point-pair geometry; content recovery
evaluates information decodable from one point.

\paragraph{Sampling and target hygiene.}
At each update, undirected edges are canonicalized, self loops are removed, and
positive pairs are drawn from the complete input graph.  Negative pairs are
sampled by rejection from nonedges.  If edge dropout is active in the encoder,
it affects only $E_{\mathrm{enc}}$; link positives still come from the undropped
input graph.  Content targets follow the same boundary: $\mathbf C$ is computed
from clean attributes, and labels appear only in the task loss.  This separation
prevents the recovery path from observing the target that downstream prediction
must learn.

\paragraph{Recovery implication.}
Let $D$ be a deterministic decoder and let $d_T$ be a distance on the target
space.  If $d_T(D(\operatorname{Enc}(G)),T(G))\leq\epsilon$ on the evaluation
domain, then two graphs $G_1,G_2$ with the same representation satisfy
\begin{equation}
 d_T(T(G_1),T(G_2))\leq \epsilon_{\triangle}.
 \label{eq:recoverability}
\end{equation}
Both targets lie within the recovery tolerance of the same decoded
representation, so the result follows from the triangle inequality.  Direct
recovery metrics therefore bound how much input information a shared embedding
can merge.

\subsection{Downstream modeling over the point set}
\label{sec:interfaces}
All downstream tasks use $\Hset$ as the modeling object.  Node prediction applies
a shared reader to point rows.  Graph prediction pools the set into an invariant
state.  Autoregressive graph modeling expands the set before relation decoding.
For graph tasks, we use attention pooling,
\begin{equation}
 \mathbf g=\sum_i\beta_i\mathbf U_V\mathbf h_i,\qquad
 \widehat Y_G=R_{\mathrm{graph}}(\mathbf g),
 \label{eq:pool}
\end{equation}
where $\beta_i$ is normalized over the graph.

For autoregressive graph modeling, the expansion operator maps the current set to
a larger set, and the same relation decoder recovers the expanded graph:
\begin{equation}
 \Hset_{s+1}=\operatorname{StepSet}(\Hset_s,\boldsymbol\epsilon_s),
 \qquad E_{s+1}=\{(i,j):\sigma(D_A(\mathbf h_i,\mathbf h_j))\geq\tau\}.
 \label{eq:grow}
\end{equation}
Training uses graph rule legality signals for candidate transitions; evaluation
uses fixed parameters to produce free growth rollouts and then reports terminal
validity and relational embedding probes.

\subsection{End-to-end training}
\label{sec:training}
Each downstream task is trained end to end by combining task supervision with
the two recovery losses.  The prediction loss reads labels only on the training
mask.  The link loss and content loss attach directly to $\Hset_{\mathrm{dec}}$,
so the point set remains constrained while the downstream reader learns the task.
The joint objective is
\begin{equation}
 \mathcal L=\sum_{t\in\{\mathrm{pred},\mathrm{link},\mathrm{feat},\mathrm{alive}\}}\lambda_t\mathcal L_t.
 \label{eq:objective}
\end{equation}
The survival term keeps the learned training noise scale active.  For an
embedding-only run, the prediction term is disabled and the representation is
trained only through graph recovery targets; for task runs, the task loss and
recovery losses are optimized together.

\paragraph{Evaluation setup.}
Training separates noisy encoder states from clean validation and test states.
The normalized training progress only controls noise annealing; all selection
passes and test evaluation use unperturbed relation energies.  The validation
metric selects the checkpoint, and the test split is read once from that
checkpoint.  Embedding dimension, encoder depth, head count, hidden width,
dropout, optimizer settings, loss weights, and pair budgets are treated as
experimental configuration and reported with the corresponding experiments.

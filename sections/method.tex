\section{IGSSE}
\label{sec:method}

\method{} is organized around the modeling route
\begin{equation}
 G=(V,E,\mathbf X)\ \xrightarrow{\operatorname{Enc}_{\theta}}
 \Hset=\{\mathbf h_i\}_{i=1}^{n}\ \xrightarrow{R_{\phi}}\ \widehat Y .
 \label{eq:ghy}
\end{equation}
Here $G$ is an attributed graph, $\Hset$ is a point set whose rows correspond to nodes, and
$\widehat Y$ denotes the downstream prediction.  The central design choice is to
make $\Hset$ both a prediction object and a trained recoverable representative
of $G$.
The algorithm therefore has three parts.  First, the embedding stage constructs a
point set by combining an original content coordinate $\mathbf h_{o,i}$ with a
structural deviation $\mathbf o_i$.  Second, graph recovery decodes content and
relations from $\Hset$, making trained recoverability the operational evidence
for approximate equivalence.  Third, downstream readers operate directly on $\Hset$ for node
prediction, graph prediction, and autoregressive graph modeling.
This route is defined through local operations: every point starts from its own
content coordinate, every structural update writes an adjacency selected
structural bias, and every downstream prediction reads the same point set that is
checked by recovery losses.

\subsection{Representation object and notation}
\label{sec:setup}
\method{} uses one point set as the common object for embedding, recovery, and
downstream modeling.  The input is an attributed graph with node set $V$, edge
set $E$, and attribute matrix $\mathbf X$.  The encoder maps this graph to a
matrix $\Hset$ with $n$ rows and $d$ columns.  Row $i$ is the point
$\mathbf h_i$ associated with node $i$.

The embedding stage forms each point by combining an original content coordinate
$\mathbf h_{o,i}$ and a structural deviation $\mathbf o_i$.  The recovery stage
uses a content decoder $D_C$ to recover the content target $\mathbf C$ from
single points and a relation decoder $D_A$ to recover the adjacency target
$\mathbf A$ from point pairs.  The downstream stage applies a reader $R$ to
$\Hset$ and produces the prediction $\widehat Y$.  The recovery target is
\begin{equation}
 T(G)=(\mathbf A,\mathbf C),\qquad
 \mathbf C=\operatorname{sg}(\operatorname{Enc}_{X}(\mathbf X)).
 \label{eq:recovery-target}
\end{equation}
The task label is denoted by $Y$ and can be a node label, a graph label, or a
continuous target.  Thus, the notation fixes a single data flow: the encoder
constructs $\Hset$, the recovery decoders define what graph information
$\Hset$ must preserve, and the downstream reader consumes the same $\Hset$ for
prediction.

Following Figure~\ref{fig:algorithm-core}, embedding maps node attributes to
$\mathbf h_{o,i}$, writes adjacency-conditioned structural deviation
$\mathbf o_i$, fuses the two into $\mathbf h_i$, and stacks the points into
$\Hset$.

\paragraph{Original coordinate $\mathbf h_{o,i}$.}
At layer $\ell$, $\mathbf h_{o,i}^{(\ell)}$ denotes the point state before
relation information is added.  At the first layer it is produced only from
the attribute row of node $i$:
\begin{equation}
  \mathbf h_{o,i}^{(0)}=\operatorname{Enc}_X(\mathbf x_i).
  \label{eq:baseline}
\end{equation}
For later layers, the previous fused point becomes the new original coordinate.
The shared attribute MLP uses layer normalization and outputs the model width.
This attribute-only mapping preserves the node row correspondence and supplies
the input for all structural projections.

When several original coordinates are identical or nearly identical, the
training path adds an independent zero-mean perturbation before the attention
projections:
\begin{equation}
 \widetilde{\mathbf h}_{o,i}^{(\ell)}=\mathbf h_{o,i}^{(\ell)}+
 \sigma_i g(u)\boldsymbol\epsilon_i,
 \qquad \boldsymbol\epsilon_i\sim\mathcal N(\mathbf 0,\mathbf I).
 \label{eq:state-noise}
\end{equation}
The perturbed states produce distinct query, key, and value vectors, so the
global bias and adjacency selected writes can move initially coincident points
in different directions.  The perturbation is an encoding component rather
than a node identifier or a structural target.  Its learned scale and a
reproducible noise realization are retained in the inference path, so this
separation mechanism is not an optional training-only mode.

\paragraph{Structural deviation $\mathbf o_i$.}
The structural branch first forms a global structural bias from the current
content coordinates and then uses adjacency to select the writes to each target
point.  For each attention head, query, key, and value vectors are computed as
follows:
\begin{equation}
\mathbf q_i^{(m)}=\mathbf W_Q^{(m)}\widetilde{\mathbf h}_{o,i}^{(\ell)},\quad
\mathbf k_i^{(m)}=\mathbf W_K^{(m)}\widetilde{\mathbf h}_{o,i}^{(\ell)},\quad
\mathbf v_i^{(m)}=\mathbf W_V^{(m)}\widetilde{\mathbf h}_{o,i}^{(\ell)}.
\label{eq:qkv}
\end{equation}
For the attention energy $e_{si}^{(m)}$, the perturbation scale is generated by
a shared noise-scale network:
\begin{equation}
 \begin{aligned}
 \sigma_{si}^{(m)}&=\operatorname{clip}_{[0,\sigma_{\max}]}
 \left(\operatorname{Softplus}\left(\psi_\sigma([e_{si}^{(m)};u])\right)\right),\\
 g(u)&=\max(0,1-u),\qquad u\in[0,1].
 \end{aligned}
 \label{eq:noise-scale}
\end{equation}
Here $u$ is normalized embedding progress, $g(u)$ is the scheduled amplitude,
and $\psi_\sigma$ is a lightweight projection shared across nodes and layers.
The scale is computed per incoming relation and attention head; $\bar\sigma$
denotes its mean value used by the survival auxiliary loss.
The projections form the point compatibility field.  Dense attention over all
points then produces the global structural bias:
\begin{equation}
\mathbf u_s^{(m)}=\sum_j\operatorname{softmax}_j\!\left(
\frac{(\mathbf q_s^{(m)})^\top\mathbf k_j^{(m)}}{\sqrt{d_h}}\right)
\mathbf v_j^{(m)}.
\label{eq:source-summary}
\end{equation}
Query and key projections determine interaction weights, while the value
projection determines the carried information.  Recovery and prediction losses
backpropagate through the fused points to these projections, so the bias is
learned for both graph reconstruction and downstream prediction.
The adjacency defines the write set for each target:
\begin{equation}
 N_A(i)=\{s:(s,i)\in E\}\cup\{i\}.
 \label{eq:write-set}
\end{equation}
The bias already contains global attention information, while adjacency selects
the source points written to each target.  Reusing the pairwise energy from the
global interaction, the local write weights are
\begin{equation}
 \alpha_{si}^{(m)}=\frac{\exp(e_{si}^{(m)})}
 {\sum_{r\in N_A(i)}\exp(e_{ri}^{(m)})},\qquad s\in N_A(i).
 \label{eq:local-write-weight}
\end{equation}
The multihead write defines the deviation:
\begin{equation}
 \mathbf o_i^{(\ell)}=\Psi^{(\ell)}(\widetilde{\mathbf H}_o,\mathbf A)_i
 =\mathbf W_O\Vert_m\sum_{s\in N_A(i)}\alpha_{si}^{(m)}\mathbf u_s^{(m)}.
 \label{eq:deviation}
\end{equation}
The deviation is added to the original coordinate.  The self term keeps
isolated nodes active, and the softmax controls incoming write strength.  The
state perturbation above is applied before the projections, so it changes both
the values being written and the write weights.  This is the mechanism that
separates compressed point states during embedding and inference; the learned
structural deviations and replayable perturbation are used together.

\paragraph{Fusion into $\mathbf h_i$.}
The fusion branch adds the content coordinate and structural deviation, applies
dropout to the deviation branch, and uses a normalized feedforward update:
\begin{equation}
 \mathbf h_i^{(\ell)}=\Phi\!\left(\mathbf h_{o,i}^{(\ell)}+\operatorname{Dropout}(\mathbf o_i^{(\ell)})\right).
 \label{eq:fusion}
\end{equation}
The fused point becomes the original coordinate for the next layer.  After the
last layer, stacking all final points gives the point set used by recovery and
downstream readers:
\begin{equation}
 \Hset_{\mathrm{dec}}=\mathbf H^{(L)}.
 \label{eq:decoder-state}
\end{equation}
The final layer yields $\Hset_{\mathrm{dec}}$ for recovery; the configured
task reader consumes this final state or the selected intermediate states when
jump connections are enabled.  Thus the core data flow remains
content coordinate, structural deviation, fused point, and point set.

\subsection{Approximate equivalence of the point set}
\label{sec:recovery}
Recovery uses $\Hset$ as the modeling object.  The relation decoder reads two
points and recovers whether a graph relation exists; the content decoder reads
one point and recovers its content target.  Together, the two decoders make the
trained point set an approximate equivalence class of the graph under the chosen
recovery targets.  This approximate equivalence is an empirical property of the
trained encoder and decoders, assessed by recovery behavior and embedding scores
on the evaluated data.

The relation decoder projects final point rows to head specific queries and
keys, scores their scaled inner product, symmetrizes undirected relations, and
applies a learned scale and bias.  For a candidate pair $(i,j)$,
\begin{equation}
 s_{ij}=\rho\,\operatorname{Mean}_{m,\leftrightarrow}\!\left(\frac{(\overline{\mathbf q}_i^{(m)})^\top\overline{\mathbf k}_j^{(m)}}{\sqrt{d_h}}\right)+\beta,\quad \widehat A_{ij}=\sigma(s_{ij}).
 \label{eq:pairattn}
\end{equation}
The link loss applies binary cross entropy to the relation score and the
adjacency target.  Its gradient updates the pair decoder projections, the
learned scale and bias, and the encoder parameters that produced the two endpoint
points.  Positive pairs increase the compatibility of endpoint projections,
while sampled negative pairs reduce the compatibility of nonedge projections.
Because the endpoint points come from the same point set consumed by the task
reader, link recovery also shapes the embedding geometry used by downstream
prediction.  The content decoder is
\begin{equation}
 \widehat{\mathbf C}=D_C(\Hset_{\mathrm{dec}}).
 \label{eq:feat}
\end{equation}
Equivalently, the decoder acts pointwise as
\begin{equation}
 \widehat{\mathbf c}_i=D_C(\mathbf h_i),\qquad
 \mathcal L_f=\frac{1}{n}\sum_{i=1}^{n}
 \lVert\widehat{\mathbf c}_i-\operatorname{sg}(\operatorname{Enc}_X(\mathbf x_i))\rVert_2^2.
 \label{eq:content-recovery}
\end{equation}
The content target uses a stopped-gradient attribute embedding rather than raw
attributes so heterogeneous feature dimensions are mapped into the model space
before recovery.  Since this embedding initializes the content coordinate and
also feeds the task and structural paths, task and relation supervision shape
it while the stop-gradient target prevents the content decoder from pulling the
target branch toward a trivial solution.  The content loss measures mean squared error between the predicted content and
the content target.  Its gradient updates the point level decoder and the
encoder path that forms each point, encouraging each point to retain its content
coordinate while accepting relation conditioned structural deviation.  Relation
recovery evaluates point pair geometry; content recovery evaluates information
decodable from one point.
The relation decoder uses normalized projections before the scaled inner
product.  This keeps the score controlled by angular compatibility and a learned
global scale, which is useful when different graphs have different sizes or
feature magnitudes.  For directed graphs the symmetrization operator is removed;
for undirected graphs both directions share the same recovered score.  Edge
attributes, when present, are predicted by a separate pair decoder over
the two endpoint points after the binary relation score selects the relevant
pairs.

For recovery, positive pairs come from the complete input graph and an equal
number of negative nonedges is sampled.  Input edge dropout affects encoding
only; clean relation and content targets are retained, while task labels enter
only the prediction loss.

\paragraph{Trained recoverability.}
The jointly optimized content MSE and relation BCE provide empirical recovery
signals for the selected targets.  Thus individual points retain content,
point pairs retain relations, and the trained point set functions as an
approximate equivalence class on the evaluated data, measured by Emb, recovery,
and downstream scores.

\subsection{Downstream modeling over the point set}
\label{sec:interfaces}
All downstream tasks use $\Hset$ as the modeling object.  Node prediction applies
a shared reader to point rows.  Graph prediction pools the set into an invariant
state.  Autoregressive graph modeling expands the set before relation decoding.
For graph tasks, we use attention pooling,
\begin{equation}
 \mathbf g=\sum_i\beta_i\mathbf U_V\mathbf h_i,\qquad
 \widehat Y_G=R_{\mathrm{graph}}(\mathbf g),
 \label{eq:pool}
\end{equation}
where $\beta_i$ is normalized over the graph.
The pooling scores are normalized within each graph and weight projected point
values.  Node tasks read point rows with a task head; graph tasks apply this
pooling followed by a graph head.  The task loss updates the reader and the
encoder that produces the point set.

For autoregressive graph modeling, the expansion operator maps the current set to
a larger set, and the same relation decoder recovers the expanded graph:
\begin{equation}
 \Hset_{s+1}=\operatorname{StepSet}(\Hset_s,\boldsymbol\epsilon_s),
 \qquad E_{s+1}=\{(i,j):\sigma(D_A(\mathbf h_i,\mathbf h_j))\geq\tau\}.
 \label{eq:grow}
\end{equation}
During rollout, $\operatorname{StepSet}$ summarizes the current set, combines
the summary with step noise, proposes and appends a point, and refines the
augmented set.  $D_A$ decodes candidate edges, and the selector ranks candidates
with relation scores and graph-rule legality before retaining the next states.

\subsection{End to end optimization}
\label{sec:training}
Each task jointly optimizes prediction and recovery on the point set.  The joint objective is
\begin{equation}
 \mathcal L=\lambda_{\mathrm{pred}}\mathcal L_{\mathrm{pred}}
 +\lambda_l\mathcal L_l+\lambda_f\mathcal L_f+\lambda_e\mathcal L_e.
 \label{eq:objective}
\end{equation}
Here $\mathcal L_l$ is the pairwise relation BCE, $\mathcal L_f$ is the
pointwise content MSE, and $\mathcal L_e$ is the survival term
\begin{equation}
 \mathcal L_e=-\log\bigl(\max(\bar\sigma,\epsilon)\bigr),\qquad \epsilon>0.
 \label{eq:alive-loss}
\end{equation}
Here $\mathcal L_l$, $\mathcal L_f$, and $\mathcal L_e$ update the relation
decoder, content path, and state-noise scale, respectively, while prediction
updates the task reader and encoder.  Embedding-only runs omit prediction;
task runs optimize all active terms together.
Unless otherwise stated, prediction and link recovery losses use unit weight,
content recovery uses weight 0.1, and the survival term uses weight 0.001.  The
default encoder uses width 128, three layers, four attention heads, hidden width
four times the model width, and dropout 0.1.  Relation recovery samples up to
4096 positive pairs per update and matches them with the same number of negative
pairs.  Optimization uses AdamW with learning rate 0.001, weight decay 0.0001,
and gradient clipping at 1.0.
State perturbations are scheduled through the embedding process and retained
with their learned scale and replayable realization during inference, coupling
the encoder, recovery decoders, and task reader throughout the representation
path.

\paragraph{Complexity.}
With width $d$, attribute projection and feedforward fusion cost
$O(nd^2)$ per layer, while adjacency-conditioned writing costs
$O((n+|E|)d)$.  Sampled pair recovery uses at most $S$ positive and negative
pairs per update and costs $O(Sd)$ for decoding, avoiding materialization of a
dense $n\times n$ reconstruction matrix.  The dense global bias is
$O(n^2d)$; it is the explicit long-range interaction term and can be replaced
by a linear or inducing-point attention implementation when graph scale
requires it.  IGSSE therefore controls structural coordinate width through the
fixed model dimension $d$ rather than a rank-sized precomputed coordinate.

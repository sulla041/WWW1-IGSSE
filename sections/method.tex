\section{IGSSE}
\label{sec:method}

\method{} is organized around three algorithmic stages.  First, the embedding
stage maps an attributed graph to a point set $\Hset$ by adding an original
content coordinate $\mathbf h_{o,i}$ and a structural deviation $\mathbf o_i$
for every node.  Second, graph recovery decodes node content and point pair
relations from $\Hset$, making recoverability the guarantee of approximate
equivalence.  Third, downstream readers use $\Hset$ as their modeling object for
feature prediction, graph prediction, and autoregressive graph modeling.

\subsection{Representation object and notation}
\label{sec:setup}
Let $G=(V,E,\mathbf X)$ be an attributed graph with adjacency $\mathbf A$ and
$n$ nodes.  The task label $y$ is a node class, graph label, or continuous
target.  The embedding path uses graph attributes and relations, and \method{} produces
$\Hset\in\mathbb R^{n\times d}$, where row $i$ remains associated with node
$i$.  This row correspondence is essential: a content decoder must read a node
target from one point, while a relation decoder must read a graph relation from a
pair of points.

We distinguish the embedding target from the prediction target.  The recovery
target is $T(G)=(\mathbf A,\mathbf C)$, where
$\mathbf C=\operatorname{sg}(\operatorname{Enc}_{X}(\mathbf X))$ and
$\operatorname{sg}$ stops gradients.  A configuration may instead recover a
standardized raw feature target.  In either case, labels are excluded.  The
stopped encoded target prevents the feature decoder from reducing reconstruction
to a shortcut through the target encoder.  We reserve $\Hset_{\mathrm{dec}}$
for the final state verified by the two decoders, and reserve
$\Hset_{\mathrm{task}}$ for a final state or jump concatenated reader input.
This separation fixes the recovered representation object before task readout.

\paragraph{Core path correspondence.}
Figure~\ref{fig:algorithm-core} summarizes the computation graph used in this
section. Table~\ref{tab:notation} lists the symbols used by the algorithm.  The
embedding stage has two explicit components.  The first component is the
original coordinate $\mathbf h_{o,i}$, which carries node content before a
structural write.  The second component is the structural deviation
$\mathbf o_i$, which is computed from global source states and written through
the observed adjacency.  Their sum forms the fused point state
$\mathbf h_i$.  This design matches the figure: the encoder creates content
points, relation conditioned writing injects structural deviations, and the
output point set $\Hset$ is then passed to recovery and downstream readers.
The first layer path is
\begin{align}
 \mathbf x_i&\rightarrow\mathbf h_{o,i}\rightarrow
 (\mathbf Q,\mathbf K,\mathbf V)\rightarrow E^{\mathrm{global}}
 \rightarrow\mathbf u_s,\nonumber\\
 \mathbf u_s&\rightarrow\alpha_{si}\rightarrow\mathbf o_i\rightarrow
 \mathbf r_i=\mathbf h_{o,i}+\mathbf o_i\rightarrow\mathbf h_i.
 \label{eq:visual-core}
\end{align}
Later layers repeat this path with the preceding point state in place of
$\mathbf h_o$. The conditional noise filter regulates structural writing when
global source states contract during aggregation.

\subsection{Embedding by content coordinates and structural deviations}
\label{sec:fsde}
The embedding stage constructs $\Hset$ by repeating the same two component
operation over layers.  At layer $\ell$, let $\mathbf h_{o,i}^{(\ell)}$ denote
the original coordinate that will receive the structural write.  At the first
layer this coordinate comes from the attribute encoder,
\begin{equation}
  \mathbf h_{o,i}^{(0)}=\operatorname{Enc}_X(\mathbf x_i).
  \label{eq:baseline}
\end{equation}
For later layers, $\mathbf h_{o,i}^{(\ell)}=\mathbf h_i^{(\ell-1)}$.  In the
default implementation, $\operatorname{Enc}_X$ applies input layer
normalization, a linear map to a hidden space, GELU and dropout, a second linear
map, and output normalization.  Formally,
\begin{align}
 \widetilde{\mathbf x}_i&=\operatorname{LN}_{\mathrm{in}}(\mathbf x_i),\\
 \mathbf z_i&=\operatorname{Dropout}\bigl(
 \operatorname{GELU}(\widetilde{\mathbf x}_i\mathbf W_1+\mathbf b_1)\bigr),\\
 \mathbf h_{o,i}^{(0)}&=\operatorname{LN}_{\mathrm{out}}(\mathbf z_i\mathbf W_2+\mathbf b_2).
 \label{eq:feature-encoder}
\end{align}
This encoder has no access to $E$, so its output provides an explicit content
reference for the subsequent structural correction and for the content target.
The baseline gives a concrete location for node content before graph
conditioning.

\paragraph{Original coordinate $\mathbf h_{o,i}$.}
The original coordinate is the content carrier of each point.  It is shared
across all subsequent operations in the layer: query, key, and value projections
are computed from $\mathbf h_{o,i}^{(\ell)}$, and the final fusion keeps a
direct residual path from this coordinate to $\mathbf h_i^{(\ell)}$.  At layer
$\ell$, multihead projections produce $\mathbf q_i$, $\mathbf k_i$, and
$\mathbf v_i$ for every node. For source $s$, target $i$, and head $m$,
\method{} computes the global pair energy
\begin{equation}
 e_{si}^{(m)}=\operatorname{LeakyReLU}\left(
 (\mathbf a_{\mathrm{src}}^{(m)})^\top\mathbf q_s^{(m)}+
 (\mathbf a_{\mathrm{dst}}^{(m)})^\top\mathbf k_i^{(m)}\right).
 \label{eq:energy}
\end{equation}

The global attention field then forms contextual source states
\begin{equation}
 \mathbf u_s^{(m)}=\sum_{j\in V}
 \operatorname{softmax}_{j}(e_{sj}^{(m)})\mathbf v_j^{(m)}.
 \label{eq:global-source}
\end{equation}
The adjacency defines the write set
$N_A(i)=\{s:(s,i)\in E\}\cup\{i\}$ for each target $i$.

\paragraph{Noise curriculum.}
The noise network $\psi$ receives the mean head energy and a normalized training
progress $u$.  It predicts a nonnegative scale $\sigma_{si}^{(m)}$, and training
uses
\begin{equation}
 \widetilde e_{si}^{(m)}=e_{si}^{(m)}+
 \sigma_{si}^{(m)}\max(0,1-u)\epsilon_{si}^{(m)},\qquad
 \epsilon_{si}^{(m)}\sim\mathcal N(0,1).
 \label{eq:noise}
\end{equation}
More specifically, the mean energy $\bar e_{si}=M^{-1}\sum_m e_{si}^{(m)}$
and progress $u$ enter a two layer MLP:
\begin{align}
 \log\sigma_{si}&=\operatorname{MLP}_{\psi}([\bar e_{si},u])+
 \log\sigma_0,\\
 \sigma_{si}^{(m)}&=\min\{\operatorname{softplus}(
 \log\sigma_{si}^{(m)})+10^{-4},1.5\}.
 \label{eq:scale}
\end{align}
Each head therefore receives its own edge dependent perturbation scale.  The
survival term in Eq.~\eqref{eq:objective} prevents this scale from trivially
vanishing during the noise phase.
Evaluation sets $\widetilde e=e$.  The curriculum perturbs early relation
weights, then removes the perturbation before selection and test evaluation.
The noise filter belongs to the structural writing configuration.

\paragraph{Structural deviation $\mathbf o_i$.}
The structural deviation is the relation dependent correction written to the
original coordinate.  For each target, a softmax over $N_A(i)$ gives
$\alpha_{si}^{(m)}$.  The projected multihead sum defines
\begin{equation}
 \mathbf o_i^{(\ell)}=\mathbf W_O\left\Vert_m
 \sum_{s\in N_A(i)}\alpha_{si}^{(m)}\mathbf u_s^{(m)}
 \right\Vert.
 \label{eq:deviation}
\end{equation}
In the embedding path, this term summarizes relation selected global source
states and therefore encodes the structural deviation between the content
coordinate and the graph conditioned point.

\paragraph{Fusion into $\mathbf h_i$.}
The point state is produced by adding the original coordinate and the structural
deviation, then applying normalization and a feedforward map:
\begin{equation}
 \mathbf r_i^{(\ell)}=\mathbf h_{o,i}^{(\ell)}+
 \operatorname{Dropout}(\mathbf o_i^{(\ell)}).
 \label{eq:add-fusion}
\end{equation}
\begin{align}
 \widehat{\mathbf h}_i^{(\ell)}&=\operatorname{LN}(\mathbf r_i^{(\ell)}),\\
 \mathbf h_i^{(\ell)}&=\widehat{\mathbf h}_i^{(\ell)}+
 \operatorname{FFN}(\widehat{\mathbf h}_i^{(\ell)}).
 \label{eq:fusion}
\end{align}
After $L$ layers, $\Hset_{\mathrm{dec}}=\mathbf H^{(L)}$ is used for recovery.
Node tasks may use this final state or a jump concatenated state
$\mathbf h_{o,i}^{(0)}\Vert\mathbf h_i^{(1)}\Vert\cdots\Vert\mathbf h_i^{(L)}$.

\paragraph{Pseudocode 1: embedding by content coordinate and structural deviation.}
\begin{quote}\small
\textbf{Input:} $\mathbf X$, $E_{\mathrm{enc}}$, and progress $u$.\\
\textbf{Output:} $\Hset_{\mathrm{dec}}$, $\Hset_{\mathrm{task}}$, and
mean noise scale $\overline\sigma$.\\
\textbf{1.} Initialize $\mathbf h_{o,i}^{(0)}\leftarrow
\operatorname{Enc}_X(\mathbf x_i)$ for every node.\\
\textbf{2.} At layer $\ell$, set $\mathbf h_{o,i}^{(\ell)}$ to the current
content coordinate, then project it to queries, keys, and values.\\
\textbf{3.} Compute global pair energies $e_{si}$ and contextual source states
$\mathbf u_s$. Use $N_A(i)$ to normalize incoming scores and form the structural
deviation $\mathbf o_i^{(\ell)}$ by Eq.~\eqref{eq:deviation}.\\
\textbf{4.} Perturb energies with Eq.~\eqref{eq:noise} during training; use
clean energies otherwise. Form $\mathbf r_i^{(\ell)}=\mathbf h_{o,i}^{(\ell)}
+\mathbf o_i^{(\ell)}$ and apply Eq.~\eqref{eq:fusion} to obtain
$\mathbf h_i^{(\ell)}$.\\
\textbf{5.} Return the final point set $\Hset_{\mathrm{dec}}$ and the configured
task state.
\end{quote}

\subsection{Graph recovery from the point set}
\label{sec:recovery}
Graph recovery uses $\Hset$ as the modeling target.  The relation decoder reads
two points from $\Hset$ and recovers whether a graph relation exists between
them; the content decoder reads one point from $\Hset$ and recovers its content
target.  Together they make the learned point set an approximate equivalence
class of the graph under the chosen recovery targets.

The pair attention relation decoder projects final point rows to head specific
queries and keys, scores their scaled inner product, symmetrizes the two
directions for an undirected relation, and applies a learned scale and bias.  Its
projections are independent of the encoder:
$\overline{\mathbf q}_i^{(m)}=\mathbf h_i\mathbf U_Q^{(m)}$ and
$\overline{\mathbf k}_i^{(m)}=\mathbf h_i\mathbf U_K^{(m)}$.  For a candidate
pair $(i,j)$,
\begin{equation}
 \begin{aligned}
 s_{ij}&=\left(\operatorname{softplus}(\gamma)+0.5\right)
 \frac{1}{2M}\sum_m\left[
 \frac{(\overline{\mathbf q}_i^{(m)})^\top\overline{\mathbf k}_j^{(m)}}{\sqrt{d_h}}\right.\\
 &\hspace{18mm}\left.+
 \frac{(\overline{\mathbf q}_j^{(m)})^\top\overline{\mathbf k}_i^{(m)}}{\sqrt{d_h}}
 \right]+\beta,\qquad \widehat A_{ij}=\sigma(s_{ij}),\\
 \mathcal L_{\mathrm{link}}&=
 \operatorname{BCEWithLogits}(s_{ij},A_{ij}).
 \end{aligned}
 \label{eq:pairattn}
\end{equation}
Here $\gamma$ and $\beta$ calibrate score scale and offset. Pair attention reads the
final point set and is equivariant because point rows, queries, and keys permute
together.

The accompanying content decoder at the point level is
\begin{equation}
 \widehat{\mathbf C}=D_C(\Hset_{\mathrm{dec}}),\qquad
 \mathcal L_{\mathrm{feat}}=\operatorname{MSE}(\widehat{\mathbf C},\mathbf C).
 \label{eq:feat}
\end{equation}
The two losses measure complementary quantities: pair attention evaluates relation
geometry of point pairs, and $D_C$ evaluates content decodable from one final
point. Their joint evaluation defines the direct reconstruction criteria.

\paragraph{Pair sampling and target hygiene.}
Materializing every nonedge is unnecessary and can dominate the objective on a
sparse graph.  At each update, we first canonicalize an undirected edge as
$s<i$, remove self loops, and draw
$n_+=\min(\texttt{num\_pos},\max(n,64),|E^+|)$ positive pairs from the complete
input graph.  We then draw an equal size negative set by uniformly proposing
$a\neq b$, canonicalizing $(a,b)$, and rejecting every pair in $E^+$.  The
negative sampler stops after a fixed rejection budget, which makes the realized
pair count explicit for dense graphs.  If edge dropout is active in the encoder,
it affects only the computation graph $E_{\mathrm{enc}}$; link positives still
come from the undropped input graph.  This distinguishes an input perturbation
from a changed reconstruction target.  Pair attention therefore learns whether a point
set constructed under perturbation can still distinguish the target relations.

The content target has the same hygiene requirement.  In the default
configuration, $\mathbf C=\operatorname{sg}(\operatorname{Enc}_X(\mathbf X))$
uses clean attributes even when the encoder receives an input perturbation.  A
direct feature configuration replaces $\mathbf C$ by standardized $\mathbf X$.
Both variants preserve the label boundary: $y$ appears only in
$\mathcal L_{\mathrm{pred}}$ over the training mask.  This boundary prevents
the recovery path from observing the target that a downstream task is meant to
predict.

The content decoder is a layer normalized MLP applied at the point level over
$\Hset_{\mathrm{dec}}$. Feature reconstruction measures information decodable
from each final point. Its default form is a layer normalized two layer GELU MLP
with output dimension equal to the target dimension. Edge attributes use the
pair decoder $D_E(\mathbf h_i,\mathbf h_j)$ and an explicit edge attribute loss.

\subsection{Training schedule and evaluation setup}
\label{sec:training}
The optimization schedule separates three quantities that otherwise become easy
to conflate: a noisy encoder state during training, a clean deterministic state
for validation and test, and a task label visible only on training examples.
For a node task, the normalized progress is
\begin{equation}
 u=\min\left(1,\frac{\mathrm{epoch}}{0.4\,\mathrm{epochs}}\right).
 \label{eq:curriculum}
\end{equation}
The first 40\% of training therefore anneals Eq.~\eqref{eq:noise}; later
updates and all selection passes use unperturbed relation energies.  Gradient
clipping bounds the joint update, and the validation metric chooses a checkpoint.
The test split is read once from the selected checkpoint.  The default node task
configuration uses dimension 64, three encoder layers, four heads, hidden width
256, dropout 0.4, Adam at $10^{-3}$ with weight decay $5\times10^{-4}$, loss
weights $(1.0,0.5,0.3,0.02)$, and up to 4096 positive and 4096 negative pairs.

\paragraph{Pseudocode 2: one joint update.}
\begin{quote}\small
\textbf{1.} Compute $u$, optionally perturb $\mathbf X$ and the encoder edge
view, then run Pseudocode~1 with training noise enabled.\\
\textbf{2.} Decode clean content targets from $\Hset_{\mathrm{dec}}$ and compute
$\mathcal L_{\mathrm{feat}}$. Sample pairs from the complete input graph and
compute $\mathcal L_{\mathrm{link}}$.\\
\textbf{3.} Read $\Hset_{\mathrm{task}}$ with the configured node or graph head;
compute $\mathcal L_{\mathrm{pred}}$ only on training labels.\\
\textbf{4.} Add $\mathcal L_{\mathrm{alive}}$, backpropagate the weighted sum,
clip gradients, and update encoder, pair attention, content decoder, and reader jointly.\\
\textbf{5.} For selection and test, disable noise, set $u=1$, and evaluate the
selected checkpoint.
\end{quote}

The embedding probe measures whether a standardized structural feature predicts
links from the learned state. Direct recovery metrics evaluate $D_A$ and $D_C$.
The paper reports these complementary metrics separately before each point or set
prediction comparison.

\subsection{Loss attachment and gradient routes}
\label{sec:losses}
The joint objective in Eq.~\eqref{eq:objective} has four distinct attachment
points.  The prediction term supervises a task reader.  The link term sends
gradients through pair attention and the final point set.  The feature term
sends gradients through the content decoder and final point set, with the target
encoder stopped.  The survival term reaches the scale network and the
attention energy path. Relation geometry, node content, task relevance, and the
training filter receive separate signals. $\mathcal L_{\mathrm{pred}}$ reads
$y$ on the training mask; the remaining three terms use graph
information.

For an embedding only run, $\lambda_{pred}=0$ and the three representation terms
train a point set using only graph recovery targets.  A task run restores
$\mathcal L_{pred}$ and retains the other terms.  This schedule makes two
experimental modes explicit: representation training assesses the point set
alone, and a joint task run assesses the representation and reader system while
keeping the information objectives active.

\subsection{Downstream modeling over the point set}
\label{sec:interfaces}
All downstream tasks use $\Hset$ as the modeling target.  Node prediction reads
one point, graph prediction pools the whole set, and autoregressive graph
modeling expands the set before relation decoding.  This keeps the task
interface consistent with graph recovery: recovery and prediction both operate
on the same learned point set.

A shared point head maps each $\mathbf h_i$ to a node label or value.  A graph
task uses invariant attention pooling,
\begin{equation}
 \mathbf g=\sum_i\beta_i\mathbf U_V\mathbf h_i,\qquad
 \widehat Y_G=R_{\mathrm{graph}}(\mathbf g),
 \label{eq:pool}
\end{equation}
where $\beta_i$ is normalized over the graph. The readout consumes the learned
point set. The frozen $\Hset$ and readout replacement ablations isolate this
interface choice.

\paragraph{Output level choice.}
For node classification and regression, the head is shared over point rows and
preserves correspondence to nodes.  When a node needs task context, a set attention block
updates the entire point set before the shared head reads its row.  For graph
classification and regression, attention pooling or PMA maps a variable cardinality
set to one invariant state. Mean pooling supplies an ablation reference for
learned point selection. These output choices retain the same recovery target
and attribute task score changes to the reader of $\Hset$.

\paragraph{Concrete readers.}
For node classification, a shared MLP returns class logits
$\widehat{\mathbf z}_i=R_{\mathrm{node}}(\mathbf h_i)$ and optimizes masked
cross entropy.  Class weights and label smoothing, when configured, apply only
to training nodes.  For node regression, the same row wise reader returns a
scalar or vector and uses Huber or squared error; validation selects the target
regression metric.  These readers retain row correspondence, so an input permutation
permutes their outputs in the same way.

For graph tasks, a learned query or attention weight reads a set state.  A PMA
configuration uses one or more seed queries; a simpler attention configuration
uses $\beta_i\propto\exp(\mathbf w^\top\mathbf h_i)$.  Both preserve invariance
to node ordering.  The graph head then maps $\mathbf g$ to a class distribution
or continuous property. Graph level recovery losses are averaged over graphs in
the batch, maintaining a representation objective for each graph.

For legality guided autoregression, the reference construction first expands the
point set from $\Hset_s=\{\mathbf h_1,\ldots,\mathbf h_n\}$ to
$\Hset' =\{\mathbf h_1,\ldots,\mathbf h_n,\mathbf h_{n+1}\}$, then applies the
same pair attention relation decoder to recover the expanded graph.  Formally,
\begin{equation}
 \Hset_{s+1}=\operatorname{StepSet}(\Hset_s,\boldsymbol\epsilon_s),
 \qquad E_{s+1}=\{(i,j):\sigma(D_A(\mathbf h_i,\mathbf h_j))\geq\tau\}.
 \label{eq:grow}
\end{equation}
Training uses a graph rule legality signal. At evaluation, fixed parameters
produce free growth rollouts. The report includes terminal validity together with
an embedding probe for the resulting relational state.

\paragraph{State expansion, candidates, and live states.}
At a growth depth $s$, the expansion operator proposes one or more candidate
states from each live $\Hset_s$.  The relation decoder maps every candidate to
an edge score representation, and the graph rule predicate labels it legal or
illegal during training.  Candidate states can be ranked either by the
legality route (Legal) or by a learned continuation score (Net).  A live state
capacity gives the candidate tree a fixed beam width; the capacity is
recorded as $\texttt{max\_live}$ in the generation setting.

The construction and evaluation stages use separate signals.  Training
uses legality supervision to make the set transition sensitive to the graph
rules.  Free growth evaluation fixes all learned parameters, disables a
step wise rule teacher, and evaluates terminal graphs at a larger target size.
Thus, the final legality predicate measures an output property while Emb F1
measures whether the resulting point state retains a usable relation geometry.
The reported Legal and Net rows use the same target size and decoder interface
and make their live state selection rule explicit.

\paragraph{Growth objective.}
For a candidate graph $G_s$ produced from $\Hset_s$, let
$c_s=\mathbb{I}[\operatorname{legal}(G_s)]$ be the graph rule predicate.  A
legality head can optimize a binary loss $\mathcal L_{\mathrm{legal}}$ during
training, while the relation decoder continues to score the candidate graph.
The full generator objective combines the set transition signal, pairwise
recovery, and legality signal according to the active graph rule setting.
At test time, $c_s$ is never used as a step wise teacher.  It is evaluated only
after the free growth rollout to compute Valid.  This train to test separation is
what makes Legal and Net results evidence about a learned growth process rather
than a rule filtered trajectory.

\paragraph{Pseudocode 3: legality guided free growth.}
\begin{quote}\small
\textbf{Input:} learned expansion operator, pair attention decoder, initial set
$\Hset_0$, target size, selection rule, and $\texttt{max\_live}$.\\
\textbf{1.} Initialize the live state collection with $\Hset_0$.\\
\textbf{2.} Until the target size, expand every live state with
$\operatorname{StepSet}$ and decode candidate relation scores.\\
\textbf{3.} During training, attach the graph rule legality signal to each
candidate. During evaluation, use the learned transition and selection rule.\\
\textbf{4.} Rank candidates by the configured Legal or Net selection rule, retain at most
$\texttt{max\_live}$ states, and continue with their point sets.\\
\textbf{5.} Decode terminal graphs and report Valid together with Emb F1 over
the completed rollouts.
\end{quote}

\subsection{Symmetry and objective}
\label{sec:objective}
Shared point maps and relation scoring preserve the intended permutation
structure.  For a consistent node permutation $\mathbf P$,
\begin{equation}
 \begin{aligned}
 \operatorname{Enc}(\mathbf P\mathbf A\mathbf P^\top,\mathbf P\mathbf X)
 &=\mathbf P\operatorname{Enc}(\mathbf A,\mathbf X),\\
 D_A(\mathbf P\Hset)&=\mathbf P D_A(\Hset)\mathbf P^\top,\\
 \operatorname{Pool}(\mathbf P\Hset)&=\operatorname{Pool}(\Hset).
 \end{aligned}
 \label{eq:symmetry}
\end{equation}
\paragraph{Why the symmetry holds.}
The attribute map is shared across rows, so it commutes with a node permutation.
For a fixed target, permuting the incoming edge order permutes the softmax
arguments and values while preserving their weighted sum.  Residual maps, layer
normalization, and feedforward layers applied at the point level then preserve row correspondence by
induction over encoder layers.  Pair attention receives both point rows and
therefore transforms on both adjacency axes; attention pooling permutes weights
and values together, leaving the sum unchanged.  The argument assumes that any
edge dropout and noise sample are permuted consistently with the graph.

\paragraph{Recovery implication.}
Let $D$ be a deterministic decoder and let $d_T$ be a distance on the target
space.  If $d_T(D(\operatorname{Enc}(G)),T(G))\leq\epsilon$ on the evaluation
domain, then two graphs $G_1,G_2$ with the same representation satisfy
\begin{equation}
 d_T(T(G_1),T(G_2))\leq 2\epsilon.
 \label{eq:recoverability}
\end{equation}
Both targets lie within $\epsilon$ of the same decoded representation, so the
result follows from the triangle inequality.  The statement explains why direct
recovery metrics matter: they bound how much input information a shared
embedding can merge.  Exact inversion, additional edge attributes, and graph
isomorphism each require their own target and evaluation metric.

Each task instance jointly optimizes
\begin{equation}
 \mathcal L=\lambda_{\mathrm{pred}}\mathcal L_{\mathrm{pred}}+
 \lambda_{\mathrm{link}}\mathcal L_{\mathrm{link}}+
 \lambda_{\mathrm{feat}}\mathcal L_{\mathrm{feat}}+
 \lambda_{\mathrm{alive}}\mathcal L_{\mathrm{alive}},
 \label{eq:objective}
\end{equation}
where $\mathcal L_{\mathrm{alive}}=-\log(\max(\overline\sigma,10^{-4}))$
keeps the learned training noise scale active.  The prediction loss only accesses
training labels.  The recovery terms remain active in task mode, preserving an
embedding floor while the readout learns the task.

\paragraph{Computational boundary.}
The encoder aggregates only over $E_{\mathrm{enc}}$, so its layer cost is linear
in the number of encoded edges up to the head and hidden dimensions.  Relation
training uses sampled pairs, whereas a complete recovery evaluation may score a
larger evaluated pair set.  Set attention and unrestricted pair decoding can
become quadratic in the number of live points.  We therefore treat sampled pair
training, chunked decoding, and live state capacity as explicit evaluation
settings for the reported graph sizes.  The
experiments report task accuracy and validity; measured time and memory remain a
separate evidence requirement.

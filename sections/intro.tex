\section{Introduction}
\label{sec:intro}

Graphs are a central data model for the Web.  Products are linked by purchase
relations, papers by citations, users by social interactions, repositories by
program dependencies, circuits by signal paths, and molecules by chemical bonds.
Across these settings, graph representation learning turns relational data into
continuous objects that support recommendation, ranking, fraud detection,
scientific search, program analysis, electronic design, and social network
modeling \cite{hamilton2017,kipf2017,sen2008,yang2016,dong2023cktgnn,
guo2022timing}.  Neural networks operate naturally on vector spaces with stable
algebraic interfaces, whereas a graph combines attributed entities with a
permutation equivariant and sparse relation system over these entities.  The node
attributes can be placed in a matrix, while the relational structure also carries
paths, neighborhoods, motifs, and global connectivity patterns.  Web graphs add
another layer of difficulty: their content is heterogeneous, their relations are
large scale and sparse, and their downstream tasks may change as the graph
evolves \cite{sen2008,yang2016,shchur2018}.  A useful graph representation must
therefore convert structure into a continuous object while preserving the
information that makes the graph itself distinct.  This requirement is stronger
than fitting a task label: Web graph systems need embeddings that support
prediction and maintain recoverable content and relation targets.

The dominant graph neural network paradigm builds node states by repeated
message passing and neighborhood aggregation
\cite{gilmer2017,kipf2017,hamilton2017,velickovic2018,xu2019}.  This paradigm
has powered many graph learning systems, yet its computation pattern introduces
three structural bottlenecks.  First, oversmoothing drives node states toward a
small set of similar vectors as depth increases, weakening the distinction
between entities that need separate decisions \cite{li2018deeper,oono2020}.
Second, the Weisfeiler Leman
hierarchy gives a precise expressivity ceiling: standard neighborhood
aggregation follows the discrimination power of first order WL, while higher
order variants require heavier state spaces and still inherit predefined
combinatorial tests \cite{xu2019,morris2019wl}.  Third, structural compression occurs
when local neighborhoods, long paths, and global motifs are repeatedly folded
into a task hidden state.  The resulting vector can be predictive for a selected
label while losing information needed to reconstruct declared graph content and
relations.  In this sense, the standard message passing pipeline acts as a lossy
structural compressor: it updates node vectors through observed edges, then
supervises the final state by the selected task objective; explicit graph
reconstruction is usually introduced through a separate autoencoding objective
\cite{kipf2016vgae,simonyan2018graphvae}.

The core challenge is to define a graph representation whose vector form carries
a recoverable relation geometry.  If an attributed graph is mapped to a set of
vectors that preserves declared content and adjacency targets, graph modeling can
be studied through set modeling with explicit recovery criteria
\cite{zaheer2017,lee2019,wang2024graphpointset}.  The important step is to make
the point set an approximate equivalence class of the graph.  Intuitively, the
single point decoder recovers node content and the pair decoder recovers
relations; when both decoded targets stay within the declared recovery error,
the point set represents the original graph up to that approximation.  Under
this view, graphs mapped to the same point set also share decoded content and
relation targets up to the reconstruction error of the decoders.  This turns
embedding quality into an auditable property attached to declared recovery
targets, with downstream accuracy evaluated through a separate task reader.  The
equivalence class view also gives the model a concrete interface.  Points keep
node alignment, point pairs carry relation scores, invariant set readouts support
graph level prediction, and set expansion supports graph growth.  It further
gives experiments a direct diagnostic: link recovery, content recovery, and WL
collision separation evaluate the representation itself, while task metrics
evaluate the reader built on top of it.

We propose \method{} (Invertible Graph Set Space Embedding), a recoverable graph
set space embedding that implements this approximate equivalence class view.
Figure~\ref{fig:mp-igsse} organizes the comparison as two pipelines.  The upper
pipeline represents the conventional message passing paradigm: an input graph is
processed by message passing, feature aggregation, and a feature matrix, then the
representation enters an irreversible embedding stage before downstream tasks.
This row visualizes the main bottleneck described above: irreversible
aggregation can discard structural information and amplify over smoothing as
depth increases \cite{li2018deeper,oono2020}.  The lower pipeline represents the
\method{} mechanism.  The input graph is first mapped by node feature encoding
into a content baseline, the feature and structure deviation encoder writes
relational deviation into the node set, and the pair attention relation decoder
performs graph recovery from point pairs.  A content decoder at the point level
audits feature preservation, while the relation decoder audits link recovery.
The check mark in the graph recovery stage and the reversible embedding block
indicate the intended modeling contract: after the graph is embedded as a set,
the node set remains recoverable with respect to declared content and relation
targets.  Consequently, the embedded node set becomes an approximate equivalence
class of the original graph.  The resulting embedding matrix is consumed by
downstream readers, while the same recoverable set object can also support
generation through set expansion and pair attention recovery.

This design supplies both a modeling framework and an evaluation route.  On
aligned prediction tasks, \method{} compares the learned point set and its
readers against graph learning baselines using the same split, input convention,
and metric.  On recovery diagnostics, the decoders measure whether the
representation preserves declared links and content.  On WL collision graph
pairs, recovery trained point sets are tested for separation on second order and
third order WL collision cases.  On graph family growth, set expansion and pair
attention recovery are evaluated by terminal validity and embedding recovery
quality.  These evidence streams target different aspects of the same object:
the point set as an approximate equivalence class of the graph.

Our contributions are:
\begin{enumerate}
  \item \textbf{Approximate equivalence class representation.} We formulate
  graph embedding as a node aligned point set that functions as an approximate
  equivalence class with respect to declared adjacency and content recovery
  targets.
  \item \textbf{Recoverable deviation architecture.} We design an attribute only
  content baseline, a feature and structure deviation encoder, a pair attention
  relation decoder, and a content decoder at the point level to realize
  recoverable graph to set modeling.
  \item \textbf{WL collision diagnosis.} We evaluate recovery trained point sets
  on second order and third order WL collision graph pairs and show separation
  with the stated recovery criteria.
  \item \textbf{Broad empirical validation.} We evaluate ten aligned prediction
  comparisons over Web, circuit, timing, molecular, program, and social graphs,
  together with legality guided growth on planar, chordal, and bipartite graph
  families.  Across the aligned comparisons, \method{} exceeds every listed
  baseline.
\end{enumerate}

\section{Introduction}
\label{sec:intro}

Web systems reason over attributed relations among entities and content.
Products connect through purchase relations, papers connect through citations, and
researchers connect through collaboration.  Each relation graph carries two
different kinds of input: content attached to individual entities and structure
created by interactions.  The same graph may support an entity decision, a
subgraph decision, a graph level prediction, or an evolving relational state.
These outputs require readers that retain a common account of the information
preserved by the representation.

Task scores measure one downstream decision, whereas Web relation systems also
need representations whose declared entity content and relations remain
recoverable under explicit decoding objectives. Content and interaction jointly
shape retrieval, recommendation, network analysis, and future relation
formation. A useful representation thus supports both entity content recovery
and relation reconstruction.

Neighborhood aggregation architectures construct node states along observed edges
\cite{gilmer2017,kipf2017,hamilton2017,velickovic2018,xu2019}.  Global
encoders enlarge the interaction range through propagation, attention, or
state space updates \cite{gasteiger2019,wu2023sgformer,deng2024polynormer,wang2024graphmamba}.
IGSSE combines global computation with structural writing conditioned on
adjacency.
Global Q/K/V attention forms source states available across the point set, and
adjacency selects the states written into each target point. The recovery
objective specifies the relation target, content target, pair sampler, and
gradient route for this representation process.

We represent $G=(\mathbf A,\mathbf X)$ as a set aligned with nodes
$\Hset=\{\mathbf h_i\}_{i=1}^n$ in a relation geometry.  The set preserves a
row for every input node.  A content decoder at the point level must recover declared content from
$\mathbf h_i$; a pair attention decoder must recover declared relations from
$(\mathbf h_i,\mathbf h_j)$.  If both decoders have bounded error, then a shared
point set forces graphs with the same representation to have nearby declared
targets.  With respect to these declared recovery targets, the point set
functions as an approximate equivalence class of the graph;
Section~\ref{sec:objective} states the corresponding recovery bound. The recovery bound makes this information
claim measurable.

\method{} realizes this object through \emph{feature and structure deviation
encoding}.  An attribute only encoder first maps $\mathbf x_i$ to the original
coordinate $\mathbf h_{o,i}$.  Attention conditioned on relations then writes a
structural offset $\mathbf o_i$, and residual fusion produces $\mathbf h_i$.
This decomposition is necessary for the audit: $\mathbf h_o$ names what the
node carries before graph conditioning, while $\mathbf o$ names how the declared
relations modify that content.  Pair attention and content decoding at the point
level supervise the two reading paths.  Node heads and invariant set pooling then consume
$\Hset$, not the raw graph, and set expansion evolves $\Hset$ before the same
pair attention operator reconstructs an expanded graph.

\paragraph{Why generation belongs to the same representation.}
Autoregressive graph models commonly construct node or adjacency decisions in a
chosen order \cite{you2018,liao2019,dai2020,shi2020}; diffusion and score models
instead refine a graph valued state \cite{vignac2023,jo2022}.  These models
address graph generation, but they do not by themselves establish that the
continuous state used during growth preserves the declared relation geometry.  A
recoverable point set supplies a testable intermediate state: expansion proposes
$\Hset' = \{\mathbf h_1,\ldots,\mathbf h_n,\mathbf h_{n+1}\}$, pair attention
recovers the expanded relations, and free growth evaluation measures the learned
transition after training with graph family supervision.  This connects
prediction and legality guided growth through one audited object.

\paragraph{Web relevance.}
This work studies representation quality for attributed Web relation graphs and
belongs to \emph{Graph Algorithms and Modeling for the Web}.  Product
purchase relations, academic collaboration, and citation tasks provide the primary Web
evidence \cite{shchur2018,sen2008,yang2016}.  Program, circuit, timing,
molecular, and social graphs vary the relation semantics and output level; they
measure how the same representation construction supports changed task
interfaces and graph families.

Our contributions are:
\begin{enumerate}
  \item \textbf{Recoverable graph set space embedding.} We define a point set
  aligned with nodes whose feature baseline, structural deviation, pair attention
  reconstruction, and content decoder at the point level make the declared $\mathbf A$ and $\mathbf X$
  targets auditable.
  \item \textbf{One object for point, set, and growth readers.} We define
  task specific point and invariant set readers on $\Hset$, then define set
  expansion and pair attention reconstruction on the same state for legality guided
  autoregression.
  \item \textbf{Layered evidence for prediction, recovery, and growth.} We compare
  aligned prediction instances, analyze recovery losses and readers through
  ablation, and evaluate legality guided free growth with both validity and an
  embedding probe.  Across ten aligned prediction comparisons, \method{} exceeds
  every listed baseline; each result remains scoped to its split, input
  convention, training schedule, and baseline set.
\end{enumerate}

The resulting claim is focused: \method{} provides an auditable representation
interface for relation graphs, with evidence for graph prediction, direct
recovery, and legality guided growth in the evaluated settings.

\section{Introduction}
\label{sec:intro}

Web platforms, knowledge systems, and collaboration services organize entities,
content, and interactions as attributed relation graphs.  Product co-purchases,
co-authorships, and citations require a model to reason jointly about node
content and graph structure.  The resulting decisions may concern an entity, a
subgraph, or a changing relational state.  A useful representation must therefore
support more than one output level while retaining an auditable connection to its
input graph.

Message-passing neural networks encode a graph by repeatedly mixing neighbor
states \cite{gilmer2017,kipf2017,hamilton2017,velickovic2018,xu2019}.  This is an
effective path to prediction, but a strong task score alone does not establish
which relations or attributes survive in the final state.  Graph-to-set mappings
and positional encoders show that graphs can expose reusable continuous objects
\cite{wang2024graphpointset,chen2026gfse}.  Graph autoencoders, in turn, make
structure recovery explicit \cite{kipf2016vgae,simonyan2018graphvae}.  These
directions leave a practical gap: an attributed graph representation should make
both content recovery and relation recovery testable, and should preserve a
common interface for node, graph, and growth tasks.

We call this target an \emph{auditable graph set representation}.  Given
$G=(\mathbf A,\mathbf X)$ without task labels, \method{} learns a node-aligned
point set $\Hset$.  A pair decoder reads relations from point pairs, and a
content decoder reads non-label attributes from individual points.  These two
paths form a recovery gate.  The prediction and generation modules operate on
$\Hset$ rather than reopening the input graph as a task-specific computation
graph.  Figure~\ref{fig:overview} summarizes the representation interface.

\paragraph{Web relevance.}
This paper studies representation quality for attributed Web relation graphs and
belongs to \emph{Graph Algorithms and Modeling for the Web}.  The primary Web
evidence uses product co-purchase, academic collaboration, and citation graphs.
Program, circuit, timing, molecular, and social graphs stress the representation
under changed graph semantics; they do not establish cross-domain zero-shot
transfer.

Our contributions are:
\begin{enumerate}
  \item \textbf{Recoverable point-set embedding.} \method{} separates an
  edge-free feature baseline from a relation-conditioned structural deviation,
  and supervises the resulting point set with link and content recovery.
  \item \textbf{One interface for point and set tasks.} Node heads, invariant
  attention pooling, and set expansion consume the same node-aligned object,
  making output-level changes explicit rather than redefining the representation.
  \item \textbf{Layered empirical evidence.} We report aligned prediction
  comparisons, component ablations, and constrained free growth.  \method{}
  exceeds every listed baseline in all ten aligned prediction rows, spanning Web
  relation, program, circuit, timing, molecular, and social graphs
  (Table~\ref{tab:prediction}); the growth evidence and component attribution
  appear in Tables~\ref{tab:ar} and~\ref{tab:ablation}.
\end{enumerate}

The results support an interface claim, not a universal-pretraining or
cross-domain-transfer claim.  In particular, we distinguish a table-wise best
result from an unspecified field-wide ranking, and we separate validity in
constrained growth from full distribution matching (Tables~\ref{tab:prediction}
and~\ref{tab:ar}).

\section{Introduction}
\label{sec:intro}

Graphs are a central data model for the Web.  Products are linked by purchase
relations, papers by citations, users by social interactions, repositories by
program dependencies, circuits by signal paths, and molecules by chemical bonds.
Across these settings, graph representation learning turns relational data into
continuous objects that support recommendation, ranking, fraud detection,
scientific search, program analysis, electronic design, and social network
modeling \cite{hamilton2017,kipf2017,sen2008,yang2016,dong2023cktgnn,
guo2022timing}.  Neural networks operate naturally on vector spaces with stable
algebraic interfaces, whereas a graph combines attributed entities with sparse
relations that are equivariant to node permutations.  Node attributes can be
stored as a matrix, but graph structure additionally carries paths,
neighborhoods, motifs, and global connectivity patterns.  Web graphs make this
interface especially demanding: their content is heterogeneous, their relations
are organized by global structural regularities, and their tasks may change as
the graph evolves \cite{sen2008,yang2016,shchur2018}.  A useful representation
must therefore expose graph information to neural computation while preserving
the content and relations needed by downstream tasks.  Trained recoverability
provides an operational criterion for this role: when the learned decoders
recover the graph targets used in modeling, the point set can serve as an
empirical approximate equivalence class of the original graph.

The dominant graph neural network paradigm builds node states by repeated
message passing and neighborhood aggregation
\cite{gilmer2017,kipf2017,hamilton2017,velickovic2018,xu2019}.  This paradigm
has powered many graph learning systems, yet its computation pattern introduces
three structural bottlenecks.  First, oversmoothing drives node states toward a
small set of similar vectors as depth increases, weakening the distinction
between entities that need separate decisions \cite{li2018deeper,oono2020}.
Second, the Weisfeiler Leman hierarchy gives a precise expressivity ceiling:
standard neighborhood aggregation follows the discrimination power of first
order WL, while higher order variants require heavier state spaces and remain
tied to fixed combinatorial tests \cite{xu2019,morris2019wl}.  Third, local
information has a natural priority in message passing: local neighborhoods, long
paths, and global motifs are folded into the same task state, while global
patterns usually require more layers and thereby intensify oversmoothing
\cite{li2018deeper,oono2020}.  The resulting vector can be predictive for a
selected label while losing information needed to reconstruct graph content and
relations.  In this sense, the standard message passing pipeline acts as a lossy
structural compressor: it updates node vectors through observed edges, then
supervises the final state by the selected task objective; explicit graph
reconstruction is usually introduced through a separate autoencoding objective
\cite{kipf2016vgae,simonyan2018graphvae}.

The core challenge is to define a graph representation that is convenient for
neural modeling and still carries enough graph information for downstream tasks.
If an attributed graph is mapped to a set of vectors that recovers content and
adjacency targets after training, graph modeling can be formulated as set
modeling under explicit recovery objectives
\cite{zaheer2017,lee2019,wang2024graphpointset}.  The important step is to make
the point set an approximate equivalence class of the graph.  Attention based
decoders give this equivalence class an operational meaning: a single point
decoder recovers node content, and a pair decoder recovers relations.  When
these decoders recover the content and relation targets after training, the point set can
stand in for the graph in downstream modeling.  This transformation converts a
graph into a point set that neural architectures can process through point and
set operations.  Points keep correspondence to nodes, point pairs carry relation
scores, invariant set readouts support graph level prediction, and set expansion
supports graph growth.

We propose \method{} (Invertible Graph Set Space Embedding), a recoverable graph
set space embedding that implements this approximate equivalence class view.
\method{} realizes the idea by separating content formation, structural
deviation writing, recovery, and downstream reading over one point set.
Figure~\ref{fig:mp-igsse} organizes the comparison as two pipelines.  The upper
pipeline represents the conventional message passing paradigm: an input graph is
processed by message passing, feature aggregation, and a feature matrix, then the
representation enters an irreversible embedding stage before downstream tasks.
This row visualizes the main bottleneck described above: irreversible
aggregation can discard global structural information and amplify over smoothing
as depth increases \cite{li2018deeper,oono2020}.  The lower pipeline represents
the \method{} mechanism.  The input graph is first mapped by node feature
encoding into an original point set without structural deviation.  The feature
and structure deviation encoder then combines local neighborhoods, global
structural bias, and adjacency based writing to produce a point set carrying
global structural deviations.  Content and relation decoders verify that this
point set preserves node features and links after recovery training, providing
empirical evidence for its approximate equivalence to the original graph.  Downstream
modeling then operates on the point set for element prediction, graph
prediction, and autoregressive growth.
Here, global interaction forms a structural bias, observed adjacency decides
where this bias is written, and recovery fixes the point set as the
representation object before task readout.

The resulting representation gives prediction, recovery, and graph growth a
shared object.  Prediction readers consume the point set directly.  Recovery
decoders define the content and relation targets that make the point set an
approximate equivalence class.  Set expansion reuses the same representation
interface for autoregressive graph modeling.  Together, these components support
the central claim: recoverability makes the point set a controlled
representative of the graph, and downstream tasks can operate on that
representative through neural set operations.  The paper evaluates these three
uses with matched prediction tasks, direct recovery, WL collision separation,
and rule guided graph growth.

Our contributions are:
\begin{enumerate}
  \item \textbf{Approximate equivalence set embedding.} We construct a graph
  embedding route that maps an attributed graph to a point set whose rows
  correspond to graph nodes,
  using feature and link recovery to support its approximate equivalence
  to the graph.
  \item \textbf{Downstream task interfaces.} On top of the learned point set,
  we design task readers for element feature prediction, graph property
  prediction, and autoregressive graph growth through a shared set
  representation interface.
  \item \textbf{Empirical modeling evidence.} We compare \method{} with
  competitive graph modeling baselines under matched splits and metrics, show
  that recovery trained embeddings separate second order and third order WL
  collision graph pairs, and compare rule guided graph growth with competitive
  generation baselines.
\end{enumerate}

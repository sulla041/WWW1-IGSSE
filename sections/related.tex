\section{Background and Positioning}
\label{sec:related}

\paragraph{Global context and writing conditioned on adjacency.}
Message passing constructs node states by repeatedly aggregating neighboring
states \cite{gilmer2017,kipf2017,hamilton2017,velickovic2018,xu2019}.
APPNP, SGFormer, Polynormer, and graph state space models enlarge the receptive
field through propagation, global interaction, or selective state updates
\cite{gasteiger2019,wu2023sgformer,deng2024polynormer,wang2024graphmamba}.
These methods span local propagation and global interaction. \method{} forms
global Q/K/V source states, then uses adjacency to select their structural
writes. Pair attention recovers relations from the final point set, $D_C$ recovers content,
and task readers consume the resulting audited point set.

\paragraph{Structure encodings and graph reconstruction address only part of the
problem.}
Walk embeddings and positional encodings expose structural coordinates
\cite{perozzi2014,grover2016,chen2026gfse}.  Graph autoencoders make adjacency
reconstruction explicit \cite{kipf2016vgae,simonyan2018graphvae}.  Graph as
Point Set maps graphs to a point set representation that preserves information
\cite{wang2024graphpointset}.  These directions establish useful ingredients,
and IGSSE adds a more specific contract: an attribute only content baseline and
a deviation conditioned on relations form each point; pair
attention and $D_C$ then audit
the declared $\mathbf A$ and $\mathbf C$ targets; point, set, and growth readers
use the resulting object.  The distinction is methodological and defines the
representation contract used throughout the paper.

\paragraph{WL collision resolution after recovery training.}
The Weisfeiler Leman hierarchy provides a combinatorial reference for graph
distinguishability.  In particular, standard message passing GNNs relate to
first order WL, and higher order variants connect to higher order WL tests
\cite{morris2019wl}. Our diagnostic stratifies nonisomorphic graph pairs by
their first order, second order, and third order WL outcomes,
trains IGSSE recovery on each declared instance, and
tests whether the reconstructed graphs remain separate with the stated recovery
criteria. The BREC study reports recovery trained separation of
the evaluated second order and third order WL collision pairs.

\paragraph{Generation requires a recoverable intermediate state.}
Autoregressive models factor graph decisions in an ordering, while flow and
diffusion approaches evolve alternative graph valued states
\cite{you2018,liao2019,dai2020,shi2020,vignac2023,jo2022}.  IGSSE instead
expands a point set and asks pair attention to recover the enlarged relation structure.
Terminal validity and point set reconstruction quality are reported as complementary
properties of the generated state.

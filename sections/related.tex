\section{Related Work}
\label{sec:related}

\method{} connects graph algorithms, known limits of graph learning, recent
attempts to expand graph interaction range, equivalence class views of
representation, and neural set modeling.  These threads explain both why graph
models need richer interaction patterns and why the learned state should remain
recoverable before task readout.  They also motivate the proposed point set as a
recoverable representative for downstream modeling.

\paragraph{Graph algorithms for representation learning.}
Graph representation learning has developed from random walk embeddings and
neighborhood aggregation to attention, propagation, and set based modeling.
DeepWalk and node2vec learn proximity preserving node vectors from sampled graph
walks \cite{perozzi2014,grover2016}.  Message passing neural networks then made
local aggregation the dominant neural graph algorithm: graph convolution,
inductive neighborhood sampling, graph attention, and expressive aggregation
functions instantiate this template across semi supervised node prediction,
inductive learning, and graph prediction tasks
\cite{gilmer2017,kipf2017,hamilton2017,velickovic2018,xu2019}.  APPNP separates
prediction and propagation through personalized PageRank
\cite{gasteiger2019}.  Graph Mamba introduces selective state space modeling to
capture long range graph dependencies on graph derived token orders
\cite{wang2024graphmamba}.
These algorithms define the current graph learning toolkit used by Web
recommendation, citation analysis, program reasoning, electronic design, and
scientific graph prediction.

\paragraph{Known limitations of graph algorithms.}
The same algorithms face structural limits that are well documented.  Repeated
neighborhood averaging can make node states increasingly similar, producing
oversmoothing in deep graph neural networks \cite{li2018deeper,oono2020}.  The
message passing template also has expressivity bounded by the first order
Weisfeiler Leman test, while higher order variants increase the state dimension
and computational cost \cite{xu2019,morris2019wl}.  Long range dependence
creates a second bottleneck: information from many distant nodes must be
compressed into fixed width states along narrow graph cuts, a phenomenon studied
as oversquashing and linked to graph curvature and bottlenecks
\cite{alon2021bottleneck,topping2022oversquashing}.  Recent long range graph
models, including Graph Mamba, reduce locality by processing graph derived
sequences with selective state spaces, yet the learned state still needs an
empirical recovery assessment showing how graph content and relations are
retained before task readout \cite{wang2024graphmamba}.  These limitations motivate
representations that preserve graph content and relations before task readout
and make the retained information directly recoverable.

\paragraph{Recent attempts to address these limits.}
Recent work has explored several routes.  Graph Mamba uses selective state
space modeling to carry long range information over graph derived sequences
\cite{wang2024graphmamba}.  Rewiring methods alter graph connectivity to
improve information flow; locality aware
rewiring explicitly balances reducing oversquashing, respecting graph locality,
and preserving sparsity \cite{barbero2024locality}.
NeuralWalker combines random walk sequences with local message passing so that
sequence models can carry long range graph information \cite{chen2025neuralwalker}.
These advances improve interaction range and efficiency, and they still leave a
central representation question: how the learned state preserves graph content
and relations before task readout.  \method{} addresses this question by using
trained recovery to evaluate whether the learned point set functions as an
approximate equivalence class of the input graph.

\paragraph{Equivalence classes and graph representation.}
Equivalence classes provide a mathematical language for replacing an object by a
representative that preserves the quantities of interest.  In graph learning,
isomorphism partitions graphs into classes that share the same labeled structure,
and graph canonization chooses a representative for such a class.  Recent work
revisits canonization for graph representation learning and studies the
expressivity and stability tradeoff induced by canonical representatives
\cite{dong2024canonization}.  Graph as Point Set further shows that a graph can
be transformed into a set of independent points in a way that preserves graph
information for set encoders \cite{wang2024graphpointset}.  That line of work
establishes the graph-to-point-set conversion and the corresponding set
processing formulation.  \method{} uses a different construction: node
attributes first form an attribute-only coordinate, global attention forms a
structural bias, and adjacency selects how that bias is written into each
node-aligned point.  A point decoder recovers node content and a pair decoder
recovers relations, with both objectives optimized while the point set is
trained for the downstream task.  The distinction is therefore in the
coordinate construction, the explicit relation-conditioned structural write,
and the recovery-trained embedding procedure, rather than in using a set
encoder alone.
The structural branch also separates global interaction from relation writing:
global attention forms the source bias, while observed adjacency selects where
that bias is written, instead of using global attention as a final node update
followed by ordinary neighborhood aggregation.

Graph autoencoders provide a related recovery perspective.  Variational Graph
Auto-Encoders and GraphVAE commonly obtain latent node states through message
passing or graph convolutions and decode links or graph structure from those
states \cite{kipf2016vgae,simonyan2018graphvae}.  Their reconstruction objective
is typically an auxiliary autoencoding loss attached to a message-passing
latent state.  IGSSE makes recovery part of the embedding construction itself:
the attribute coordinate and adjacency-conditioned structural deviation are
trained together with pointwise content and pairwise relation decoders.  The
comparison is therefore between a message-passing latent autoencoder and a
node-aligned point-set embedding whose coordinates are explicitly written for
content and relation recovery.

\paragraph{Algorithms for set modeling.}
Set modeling supplies the neural operations used after the embedding is trained.
Deep Sets characterizes permutation invariant set functions through a shared
element map followed by invariant aggregation \cite{zaheer2017}.  Set
Transformer extends this formulation with attention over set elements and
inducing point attention \cite{lee2019}.  \method{} uses these operations after
constructing node-aligned coordinates and training content and relation
decoders.  Taken together, the route is embedding, graph-target recovery,
joint optimization, and task-specific reading of the resulting point set.

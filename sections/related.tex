\section{Background and Positioning}
\label{sec:related}

\paragraph{Graph encoders optimize utility, not necessarily auditability.}
Message passing constructs node states by repeatedly aggregating neighboring
states \cite{gilmer2017,kipf2017,hamilton2017,velickovic2018,xu2019}.
APPNP, SGFormer, Polynormer, and graph state-space models enlarge the receptive
field through propagation, global interaction, or selective state updates
\cite{gasteiger2019,wu2023sgformer,deng2024polynormer,wang2024graphmamba}.
These methods differ in how they compute task representations, but a task loss
does not by itself require a final state to decode both the observed relation
target and non-label node content.  \method{} imposes this missing requirement:
PairAttn reads relations from the final point set, $D_C$ reads content, and task
readers consume the audited point set rather than raw graph edges.

\paragraph{Structure encodings and graph reconstruction address only part of the
problem.}
Walk embeddings and positional encodings expose structural coordinates
\cite{perozzi2014,grover2016,chen2026gfse}.  Graph autoencoders make adjacency
reconstruction explicit \cite{kipf2016vgae,simonyan2018graphvae}.  Graph as
Point Set maps graphs to an information-preserving point-set representation
\cite{wang2024graphpointset}.  These directions establish useful ingredients,
but IGSSE requires a more specific contract: an edge-free content baseline and a
relation-conditioned deviation form each point; PairAttn and $D_C$ then audit
the declared $\mathbf A$ and $\mathbf C$ targets; point, set, and growth readers
use the resulting object.  The distinction is methodological rather than a claim
that any prior representation fails on every task.

\paragraph{WL diagnostics test a different question.}
The Weisfeiler--Leman hierarchy provides a combinatorial reference for graph
distinguishability.  In particular, standard message-passing GNNs relate to
1-WL, and higher-order variants connect to $k$-WL tests
\cite{morris2019wl}.  IGSSE does not claim to dominate 1-, 2-, or 3-WL.  A
separate proposed diagnostic therefore stratifies non-isomorphic graph pairs by
their 1/2/3-WL outcomes and measures empirical collisions of the learned point
set.  This test can reveal where the representation is discriminative without
turning an empirical result into a WL-equivalence theorem.

\paragraph{Generation requires a readable intermediate state.}
Autoregressive models factor graph decisions in an ordering, while flow and
diffusion approaches evolve alternative graph-valued states
\cite{you2018,liao2019,dai2020,shi2020,vignac2023,jo2022}.  IGSSE instead
expands a point set and asks PairAttn to recover the enlarged relation structure.
Terminal validity and point-set readability are reported separately because a
rule-satisfying terminal graph does not by itself establish an informative
intermediate representation.

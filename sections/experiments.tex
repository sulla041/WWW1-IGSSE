\section{Experiments}
\label{sec:experiments}

The experiments evaluate \method{} through four complementary settings.  The
feature prediction experiment begins with Web network tasks, followed by
program, circuit, timing, molecular, and social graph settings.  The
autoregressive experiment applies the same point set to rule guided graph
expansion.  The ablation experiment removes one training or readout component,
and the WL collision experiment evaluates controlled nonisomorphic graph pairs
\cite{morris2019wl,wang2023brec}.

\subsection{Feature Prediction Main Experiment}
\label{sec:feature-main}

The first prediction settings are Web network tasks: Amazon Photo models
product co-purchase structure, Coauthor-CS models collaboration structure,
Photo-interact models node representation under an interaction/freeze
protocol, and Cora models a citation network.  These tasks use node attributes
and observed relations, apply node-level readers to the point set, and evaluate
classification on ten independent splits.  They are followed by program,
circuit, timing, molecular, and social graph settings, which extend the same
interface to control-flow, continuous circuit, netlist timing, molecular, and
graph-level classification targets.

All main-table tasks use the same IGSSE embedding and recovery route.  The input
contains adjacency, node attributes, and available edge attributes; the encoder
produces $\Hset$, recovery decoders train graph targets, and task heads read
points or pooled sets.  Emb records recovery quality and Result records the
task metric.  All methods use the same input fields, checkpoint rule, and ten
independent train/validation/test split runs.

Web network tasks include Amazon Photo, Coauthor-CS, Photo-interact, and Cora.
The standard node tasks use 60/20/20 splits, Photo-interact uses freeze-one,
and Cora uses the public Planetoid fields; node labels are visible only on the
training mask and are read from point states \cite{shchur2018,sen2008,yang2016}.

HiGraph uses the official 70/15/15 IID split and Macro-F1 for control-flow
malware classification.  OCB uses Ckt-Bench-101 with an 8100/900/1000 split
and regresses FoM, gain, bandwidth, and phase margin with Pearson correlation
\cite{dong2023cktgnn}.  TimingPredict uses directed netlists and design-level
partitions, with predecessor pooling for delay regression and coefficient of
determination as the primary metric \cite{guo2022timing}.  AIDS, IMDB-MULTI,
and IMDB-BINARY use stratified ten-fold graph classification with set attention
or PMA pooling and accuracy as the primary metric \cite{morris2020,yang2015}.

The baseline set represents neighborhood computation, propagation, long range
sequence modeling, and graph to point set modeling.  GCN, GraphSAGE, GAT, and
GIN use standard neighborhood aggregation
\cite{kipf2017,hamilton2017,velickovic2018,xu2019}.  APPNP adds personalized
PageRank propagation \cite{gasteiger2019}.  SGFormer and Polynormer provide
global propagation alternatives \cite{wu2023sgformer,deng2024polynormer}.
Graph Mamba models long range graph dependencies with selective state spaces
\cite{wang2024graphmamba}, while PST maps a graph into a point set
\cite{wang2024graphpointset}.  The comparison therefore covers both local and
global graph processing as well as a point set representation.

The table reports Emb recovery quality and the task-specific Result; all methods
use the same input fields, split, checkpoint rule, and primary metric.

Across the ten rows, the complete IGSSE configuration attains the highest
reported Result in each task and the strongest Emb value in the corresponding
comparison.  The pattern spans Web node classification, program and circuit
graphs, directed timing graphs, and graph classification, so the observed gain
is associated with the joint content-structure representation rather than a
single task head.  The comparison is empirical: each dataset is trained and
selected independently under its stated split protocol.

\subsection{Autoregressive Graph Modeling}
\label{sec:ar-results}

The autoregressive experiment applies the point set produced by \method{} to
four rule guided rollout settings.  At each step, the expansion operator
proposes a new point, the pair relation decoder determines its graph relations,
and the rule evaluator accepts a terminal graph when the required constraint is
satisfied.  Planar Legal and Planar Net specify planar graph validity, Chordal
specifies chordal structure, and Bipartite specifies a two part relation
constraint.  These task specifications test whether point addition and relation
formation remain coherent throughout graph growth.

The comparison covers GraphRNN and GRAN for autoregressive graph generation,
BiGG as a sparse autoregressive generator, SPECTRE as a spectral-conditioned
one-shot GAN, EDGE as an edge-based diffusion model, and GDSS as a score-based
generator
\cite{you2018,liao2019,dai2020,martinkus2022spectre,chen2023edge,jo2022}.
Emb measures the
embedding result associated with the rollout, while Valid is the fraction of
terminal rollouts that satisfy the specified graph rule.
Each rollout starts from the prescribed initial state and repeatedly proposes a
point until the target size is reached or the selector emits a terminal state.
The relation decoder is evaluated on the expanded set at every step.  Valid is
computed only from the terminal graph, so intermediate candidates do not count
as successful samples.  This protocol makes the four task rows comparable
while preserving their different graph constraints.

Table~\ref{tab:autoregressive-results} keeps the Metric column and reports the
Valid field for each task.  All methods use the same rollout setting and
terminal rule.  \method{} reaches the highest Valid value on Planar, PlanNet,
Chordal, and Bipartite, establishing that the shared point set
interface supports rule guided graph expansion.

\subsection{Ablation Experiment}
\label{sec:ablation}

The ablation keeps the dataset, split, schedule, and task head fixed while
changing one representation component.  In Table~\ref{tab:ablation-results},
$-L_f$ removes content recovery, $-\Psi$ removes structural deviation writing,
$-L_l$ removes relation recovery, $-L_e$ removes the embedding auxiliary term,
and \textit{freeze} fixes the trained point set while optimizing the task
reader.  Metric retains each dataset's native F1, correlation, coefficient of
determination, or accuracy.

The complete configuration is the reference point for every ablation row.  The
largest changes occur when relation recovery or structural writing is removed
on topology-sensitive tasks such as OCB and Cora, while freezing the point set
removes task-side adaptation.  These comparisons indicate that content
preservation, relation recovery, and learned structural writing contribute
jointly to the reported downstream scores.

\subsection{WL Collision Experiment}
\label{sec:wl-diagnostic}

The WL3 collision experiment tests whether recovery-trained embeddings separate
graph pairs that iterative color refinement cannot separate.  In the WL
procedure, each node starts with an initial color and repeatedly replaces it by
a hash of its current color and the multiset of neighbor colors.  A pair that
retains the same color histogram after the specified number of rounds is a WL
collision for that diagnostic.  BREC provides controlled nonisomorphic graph
pairs for realized GNN expressiveness studies \cite{wang2023brec}; the present
evaluation uses 35 pairs each for Basic, Regular, Extension, and CFI, and 20
pairs each for 4-Vertex Condition and Distance Regular.  Exact pair IDs, node
counts, and graph encodings are retained in the experiment manifest; node
attributes are constant within each graph.

The table reports the pair count and collision rate for the shared GNN, GIN,
and IGSSE evaluation.  A collision rate of one means that every pair in the
category remains collided, while zero means that every pair is separated by the
evaluated representation.  GNN and GIN retain collision rate one across all
listed categories, whereas the recovery-trained IGSSE embedding reaches zero
collision rate across the same WL3 diagnostic pairs.  This result demonstrates
that, under the stated training and evaluation protocol, the learned IGSSE
embeddings can exceed the separation achieved by the tested 3-WL-limited
baselines on the selected BREC pairs; it is not a universal expressivity
theorem for all graphs.

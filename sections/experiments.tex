\section{Experiments}
\label{sec:experiments}

The experiments evaluate \method{} along four complementary axes.  The feature
prediction experiment is the main comparison and tests whether the recovered
point set supports supervised graph learning across Web relation, program,
circuit, timing, molecular, and social graph data.  The autoregressive
experiment tests whether the same set object can be expanded under graph rule
supervision.  The ablation experiment separates the contribution of recovery,
structural deviation, training perturbation, and set reading.  The WL collision
experiment tests whether recovery trained point sets separate controlled
nonisomorphic graph pairs.  Across all experiments, each dataset uses its own
encoder, recovery decoders, and task reader; validation metrics select
checkpoints and test splits report the final metric.

\subsection{Feature Prediction Main Experiment}
\label{sec:feature-main}

The main experiment compares \method{} with graph learning baselines under
matched splits, input attributes, and task metrics.  The datasets cover four
types of graph semantics.  Amazon Photo, Coauthor CS, and Cora represent product
purchase, academic collaboration, and citation relations
\cite{shchur2018,sen2008,yang2016}.  HiGraph evaluates hierarchical program
graphs for malware analysis \cite{chen2025higraph}.  OCB and TimingPredict
evaluate circuit connectivity and pre routing timing prediction
\cite{dong2023cktgnn,guo2022timing}.  AIDS and IMDB provide molecular and
social graph benchmarks from standard graph learning collections
\cite{morris2020,yang2015}.  These datasets test whether the point set remains
useful when the label lives on a node, a graph, or a continuous property.

The baselines are grouped by the computation they test.  MLP uses attributes
without graph structure.  GCN, GraphSAGE, GAT, and GIN represent neighborhood
aggregation, inductive sampling, attention over neighborhoods, and expressive
aggregation \cite{kipf2017,hamilton2017,velickovic2018,xu2019}.  APPNP tests
prediction followed by personalized PageRank propagation \cite{gasteiger2019}.
Graph Mamba tests recent long range sequence style graph modeling mechanisms
\cite{wang2024graphmamba}.  PST tests a graph to point set route
\cite{wang2024graphpointset}.  \method{} is evaluated by feeding the learned
point set to the corresponding point or set reader.  Table~\ref{tab:feature-exp}
summarizes the main comparison.

\subsection{Autoregressive Graph Modeling}
\label{sec:ar-results}

The autoregressive experiment evaluates graph growth on the same representation
interface used by prediction.  Training supplies a graph rule legality signal at
the training size.  During rollout, the learned set expansion operator appends
new live points, updates the current point set, and uses the relation decoder to
recover candidate edges.  The evaluation records terminal validity, target size,
number of sampled graphs, live state capacity, selection rule, and random seed.

The graph rules are planar, chordal, and bipartite predicates.  Planar graphs
test whether growth respects a global embeddability constraint; chordal graphs
test whether the generated graph admits the required cycle structure; bipartite
graphs test whether the live state preserves a two part relation constraint.
The comparison includes autoregressive and generative graph baselines such as
GraphRNN, GRAN, GraphVAE, GraphAF, score based graph generation, and DiGress
\cite{you2018,liao2019,simonyan2018graphvae,shi2020,jo2022,vignac2023}.  These
methods represent recurrent, attention based, variational, flow based, score
based, and diffusion based graph generation.  Table~\ref{tab:ar-exp} lists the
growth settings.

point set.  Terminal validity evaluates whether the final decoded graph satisfies
the rule, while relation recovery metrics check whether the expanded set still
supports graph decoding.

\subsection{Ablation Experiment}
\label{sec:ablation}

The ablation experiment isolates which parts of \method{} account for task
utility and recoverability.  The full model uses content encoding, structural
deviation writing, relation recovery, content recovery, training perturbation,
and the set reader.  Each ablation removes or replaces one component while
keeping the dataset split and metric fixed.  The goal is to separate whether the
observed behavior comes from recoverability, structural writing, the training
perturbation, or the downstream reader.

Table~\ref{tab:ablation-exp} defines the ablation variants.  Removing link
recovery tests whether pair geometry is needed for downstream prediction.
Removing content recovery tests whether single point content preservation
matters after structural writing.  Removing structural deviation keeps the
attribute path but removes relation conditioned correction.  Freezing the point
set tests whether end to end adaptation is necessary.  Replacing the set reader
with a simpler reader tests whether the set level aggregation contributes to
graph prediction.

task utility, while drops in link or content recovery measure whether the point
set still behaves as an approximate equivalence class under the chosen recovery
targets.

\subsection{WL Collision Experiment}
\label{sec:wl-diagnostic}

The WL collision experiment evaluates representation separation on controlled
nonisomorphic graph pairs.  The Weisfeiler Leman hierarchy provides the
expressivity reference for neighborhood aggregation and higher order tests
\cite{morris2019wl}.  BREC supplies graph pairs from Basic, Regular, Extension,
CFI, Four Vertex, and Distance Regular strata, which are designed to expose
different levels of realized graph neural network expressiveness
\cite{wang2023brec}.  For each pair, \method{} is trained only with recovery
targets and decodes both graphs under consistent node permutations.

The experiment compares recovery trained \method{} with the expected behavior of
standard neighborhood aggregation and higher order WL inspired baselines
\cite{xu2019,morris2019wl}.  Separation is measured by reconstructed graph
difference, relation F1/AUC/AP, and permutation deviation.  Table~\ref{tab:wl-exp}
summarizes the WL diagnostic.

This experiment closes the evidence chain.  The main experiment measures
supervised task utility, the autoregressive experiment measures graph growth, the
ablation experiment attributes components, and the WL collision experiment tests
whether recovery trained point sets separate controlled graph pairs beyond the
standard neighborhood aggregation regime.

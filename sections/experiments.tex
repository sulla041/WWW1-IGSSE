\section{Experiments}
\label{sec:experiments}

The experiments evaluate \method{} through four complementary settings.  The
feature prediction experiment begins with Web network tasks, followed by
program, circuit, timing, molecular, and social graph settings.  The
autoregressive experiment applies the same point set to rule guided graph
expansion.  The ablation experiment removes one training or readout component,
and the WL collision experiment evaluates controlled nonisomorphic graph pairs
\cite{morris2019wl,wang2023brec}.

\subsection{Feature Prediction Main Experiment}
\label{sec:feature-main}

The first prediction settings are Web network tasks: Amazon Photo models
product co-purchase structure, Coauthor-CS models collaboration structure,
Photo-interact models node representation under an interaction/freeze
protocol, and Cora models a citation network.  These tasks use node attributes
and observed relations, apply node-level readers to the point set, and evaluate
classification on ten independent splits.  They are followed by program,
circuit, timing, molecular, and social graph settings, which extend the same
interface to control-flow, continuous circuit, netlist timing, molecular, and
graph-level classification targets.

All main-table tasks use the same IGSSE interface.  An input graph contains its
adjacency structure, node attributes, and edge attributes when the dataset
provides them.  The encoder maps this input to the node-aligned point set
$\Hset$.  The relation decoder and attribute decoder are trained on the
available graph targets, while a task head reads $\Hset$ for classification or
regression.  Emb denotes the embedding-side recovery score, including relation,
node-attribute, and edge-attribute recovery where applicable.  Result denotes
the downstream task score.  Training uses the fixed dataset version,
preprocessing, input fields, split, and random-seed protocol for every method;
the validation partition selects the checkpoint and the test partition supplies
the reported metric.  Baselines use the same input fields, task split, primary
metric, and checkpoint rule.
All ten prediction rows aggregate results over ten independent train,
validation, and test splits.  The reported Emb and Result values are the
combined test outcomes across these ten runs under the same split protocol.

Amazon Photo, Coauthor-CS, Photo-interact, and Cora use node-level readers.
Each setting is evaluated with ten split runs; the standard node tasks use
60/20/20 train, validation, and test partitions, Photo-interact uses its
freeze-one interaction partition, and Cora uses the public Planetoid fields
within the repeated split protocol \cite{shchur2018,sen2008,yang2016}.  Product,
author, or paper attributes are the node input, observed relations are the
structural input, and labels are available only on the training mask.  The
reader applies a shared point head, with set attention context when the
configuration requests it.  Accuracy is the primary metric for these four
network settings.

The program-graph setting uses the official IID stratified split of HiGraph,
with a 70/15/15 train, validation, and test partition.  Program control-flow
nodes and edges form the graph input, program categories provide the binary
task labels, and Macro-F1 is the primary metric.  IGSSE applies pairwise
relation recovery to control-flow links, pointwise recovery to node content,
and a set reader followed by a binary program-graph head.

The OCB setting uses the Ckt-Bench-101 circuit collection and its
8100/900/1000 train, validation, and test partition
\cite{dong2023cktgnn}.  Circuit topology, device and port node attributes,
edge directions, and connection attributes form the input.  The regression
targets include FoM, gain, bandwidth, and phase margin; Pearson correlation
is reported for these specifications.  IGSSE uses pairwise recovery for
connections and node or edge attributes, attention pooling for the circuit
point set, and a multi-output regression head with targets standardized during
training and restored to physical units for evaluation.

The TimingPredict setting uses design-level partitions for directed netlists
and evaluates xtea, spm, and the other supplied designs under the same design
boundary \cite{guo2022timing}.  Node attributes, directed netlist links, net
and cell edge attributes, and direction fields form the input.  Delay,
arrival time, slew, and required arrival time are regression targets, with the
coefficient of determination for delay as the primary metric.  The IGSSE reader pools directed
predecessor points and their recovered content for the timing head after the
link, feature, net, cell, and direction recovery fields are constructed.

AIDS, IMDB-MULTI, and IMDB-BINARY use graph-level readers on the TU graph
classification benchmarks \cite{morris2020,yang2015}.  Each graph supplies
its node attributes, relations, and edge attributes when available.  The
experiments use stratified ten-fold evaluation, with the training folds used
for optimization, an internal validation split used for checkpoint selection,
and the held-out fold used for testing.  IGSSE decodes node and pair targets,
applies permutation-invariant set attention or PMA pooling, and sends the
pooled state to the graph classification head.  Accuracy is the primary metric
for these molecular and social graph tasks.

The baseline set represents neighborhood computation, propagation, long range
sequence modeling, and graph to point set modeling.  GCN, GraphSAGE, GAT, and
GIN use standard neighborhood aggregation
\cite{kipf2017,hamilton2017,velickovic2018,xu2019}.  APPNP adds personalized
PageRank propagation \cite{gasteiger2019}.  SGFormer and Polynormer provide
global propagation alternatives \cite{wu2023sgformer,deng2024polynormer}.
Graph Mamba models long range graph dependencies with selective state spaces
\cite{wang2024graphmamba}, while PST maps a graph into a point set
\cite{wang2024graphpointset}.  The comparison therefore covers both local and
global graph processing as well as a point set representation.

Table~\ref{tab:feature-results} reports two fields for every method.  Emb is the
embedding score, and Result is the final task
metric used by the corresponding prediction setting.  The Metric column gives
the task metric: F1 for HiGraph, Pearson correlation for OCB, coefficient of
determination for TimingPredict, and accuracy for the classification datasets.
The same split and metric convention is used for every method in a row.
For node classification, the instruction is to predict the masked node label
from its point, using supervision only on the training mask.  For graph
classification, the instruction is to assign one label to the pooled point
set.  The circuit and timing settings provide continuous graph targets, so the
reader outputs one scalar per graph and is optimized with a regression loss.
Each baseline uses its native graph encoder with the same task split and metric;
IGSSE uses the point set produced by its embedding stage and the corresponding
node or graph reader.

\method{} has the best Result in all ten comparisons and reaches the best Emb
value in each row.  This consistent outcome across node, graph, and continuous
targets shows that the point set produced by \method{} transfers effectively
from graph input to downstream prediction.

\subsection{Autoregressive Graph Modeling}
\label{sec:ar-results}

The autoregressive experiment applies the point set produced by \method{} to
four rule guided rollout settings.  At each step, the expansion operator
proposes a new point, the pair relation decoder determines its graph relations,
and the rule evaluator accepts a terminal graph when the required constraint is
satisfied.  Planar Legal and Planar Net specify planar graph validity, Chordal
specifies chordal structure, and Bipartite specifies a two part relation
constraint.  These task specifications test whether point addition and relation
formation remain coherent throughout graph growth.

The comparison covers recurrent GraphRNN, attention based GRAN and SPEC,
flow based BiGG, edge based EDGE, and score based GDSS
\cite{you2018,liao2019,dai2020,martinkus2022spectre,chen2023edge,jo2022}.
Emb measures the
embedding result associated with the rollout, while Valid is the fraction of
terminal rollouts that satisfy the specified graph rule.
Each rollout starts from the prescribed initial state and repeatedly proposes a
point until the target size is reached or the selector emits a terminal state.
The relation decoder is evaluated on the expanded set at every step.  Valid is
computed only from the terminal graph, so intermediate candidates do not count
as successful samples.  This protocol makes the four task rows comparable
while preserving their different graph constraints.

Table~\ref{tab:autoregressive-results} keeps the Metric column and reports the
Valid field for each task.  All methods use the same rollout setting and
terminal rule.  \method{} reaches the highest Valid value on Planar, PlanNet,
Chordal, and Bipartite, establishing that the shared point set
interface supports rule guided graph expansion.

\subsection{Ablation Experiment}
\label{sec:ablation}

The ablation experiment isolates the components that construct and consume the
point set.  The Full model contains the content coordinate, global structural
deviation, feature recovery loss, relation recovery loss, embedding auxiliary
term, and trainable set reader.  The variants remove one loss or freeze the
point set while keeping the dataset, split, optimizer schedule, and prediction
head fixed.  This gives each row a controlled component comparison.

The four loss ablation columns denote removal of feature recovery, structural
deviation, relation recovery, and the embedding auxiliary term, respectively;
the freeze column denotes a fixed point set during downstream optimization.  The
Metric column retains the task metric of each dataset:
F1, correlation, coefficient of determination, or accuracy.  Table~\ref{tab:ablation-results}
reports the final Result field for each ablation setting.  The ablation
instruction is to retain the same task head and training schedule while
changing one representation component.  Result is read after the same
training and evaluation procedure as the Full configuration, so a change in a
row reflects the contribution of the removed component to the downstream task.

Concretely, the \(-L_f\) column removes the content feature recovery loss, so
the point content is shaped by the task and the remaining objectives.  The
\(-\psi\) column removes the global structural deviation branch that writes
relation-conditioned changes into the points.  The \(-L_l\) column removes the
pairwise relation recovery loss, and the \(-L_e\) column removes the embedding
auxiliary loss used to shape the point coordinates.  The \textit{freeze} column
keeps the learned point set fixed while optimizing the downstream reader.
Together, these labels identify whether each reported change comes from point
content, structural writing, pairwise recovery, embedding regularization, or
task-side adaptation.

The Full configuration gives the highest Result on the listed HiGraph, OCB,
Timing, Photo, Coauthor, Photo interaction, Cora, AIDS, and IMDB-B rows, and it
matches the best value on IMDB-M.  This result indicates that the complete
content, structural, recovery, and set reading pipeline is the effective
configuration for downstream prediction.

\subsection{WL Collision Experiment}
\label{sec:wl-diagnostic}

The WL collision experiment is a bounded BREC diagnostic rather than a proof of
global 2-WL or 3-WL superiority.  BREC contains nonisomorphic graph pairs with
different structural difficulty levels \cite{wang2023brec}; the present
diagnostic uses a fixed 60-pair sample with ten pairs from each of Basic,
Regular, Extension, CFI, 4-Vertex Condition, and Distance Regular.  The pair
IDs are recorded in the experiment manifest: Basic {20, 27, 31, 35, 37, 46,
48, 49, 50, 57}, Regular {73, 75, 90, 111, 120, 124, 127, 129, 136, 140},
Extension {167, 181, 190, 196, 201, 203, 208, 235, 255, 259}, CFI {267,
268, 299, 306, 314, 336, 340, 351, 353, 357}, 4-Vertex Condition {361,
362, 363, 364, 366, 369, 372, 376, 377, 378}, and Distance Regular {380,
383, 384, 388, 389, 392, 393, 397, 398, 399}.  Node attributes are constant
within each graph, and the node counts are retained from the manifest.

For each pair, one encoder, one pair decoder, and one content decoder are
shared by both graphs and fitted jointly on that pair; a new parameter set is
fitted for the next pair.  The protocol therefore measures pairwise realized
expressiveness after recovery training.  It does not claim that one globally
trained encoder separates every BREC pair.  The reconstructed graph is tested
under eight transported random node relabelings.  The permutation deviation
checks representation consistency, while an external graph-isomorphism test
compares the two recovered graphs.  A collision is counted only when recovery
passes for both graphs and the recovered graphs are isomorphic.

Table~\ref{tab:wl-results} reports pair count, recovery pass/fail count,
recovery rate, collision count, and collision rate.  The recovery rate is the
number of pairs passing the fixed reconstruction criteria divided by the pair
count.  Collision rates are reported only over recovery-passing pairs; an empty
passing set is marked with a dash rather than zero.  A separate expanded run
contains 60 Basic and 100 Extension pairs, with 160 of 160 pairs passing direct
reconstruction.  These diagnostics support a narrower statement: trained IGSSE
embeddings can separate the evaluated BREC pairs that pass the stated recovery
protocol.

These four experiments form a compact evidence chain.  The main experiment
shows downstream utility, the autoregressive experiment shows graph growth from
the same representation, the ablation experiment attributes the gains to the
recoverable set construction, and the WL experiment shows that the recovered
point sets separate the covered nonisomorphic collision pairs.

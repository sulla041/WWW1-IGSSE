\section{Experiments}
\label{sec:experiments}

\subsection{Questions and protocol}
We ask: (Q1) does the declared point set retain links and node content; (Q2) does
it support Web relation tasks; (Q3) which encoder and readout components account
for task utility; (Q4) can the set state free-grow beyond the training scale
without a step-wise rule teacher; and (Q5) how do graph semantics and output
level affect the result?  Each dataset trains its own encoder, decoders, and
head.  Validation metrics select checkpoints and test splits report results.
We do not interpret the independent task instances as a single zero-shot model.

The listed baselines are MLP, GCN, GraphSAGE, GAT, GIN, APPNP, SGFormer,
Polynormer, Graph-Mamba, and PST.  Each row fixes its input convention, split,
and primary metric.  The \emph{Emb} column is a structural separability probe;
it is not a substitute for direct pair-decoder recovery.  Before submission, the
camera-ready recovery table must report link F1/AUC/AP and feature R$^2$/cosine
for each primary graph family, together with optimization steps and wall time.

\paragraph{Baseline alignment.}
The prediction comparison uses the same split, input attributes, and task metric
within a row.  MLP tests attributes without graph structure.  GCN, GraphSAGE,
GAT, and GIN represent neighborhood aggregation; APPNP, SGFormer, Polynormer,
and Graph-Mamba add different propagation or long-range mechanisms; PST tests a
graph-to-set route.  The comparison answers a row-level question: whether the
declared \method{} configuration improves the task metric under that protocol.

\paragraph{Web relation tasks.}
Amazon Photo, Coauthor-CS, and Cora respectively represent product co-purchase,
academic collaboration, and citation relations \cite{shchur2018,sen2008,yang2016}.
\method{} is best among the listed baselines in all four Web rows, including the
Photo interact protocol.  The gains on Photo and Coauthor-CS are narrow, which
is consistent with strong aligned baselines; the Cora row has a larger gap.
We therefore use the table to support Web-task utility, not to infer an
unmeasured transfer property.

\paragraph{Cross-semantic stress tests.}
HiGraph, OCB, and TimingPredict change graph semantics and output granularity,
while AIDS and IMDB add molecular and weak-feature social graph conditions
\cite{chen2025higraph,dong2023cktgnn,guo2022timing,morris2020,yang2015}.
The point and set interfaces remain available in each setting, but parameters are
trained separately.  The tests establish architectural coverage under changed
semantics, not a claim that one checkpoint transfers across all domains.

\subsection{Constrained autoregressive growth}
\label{sec:ar-results}
The generation experiment trains set expansion with graph-family rule supervision,
then freezes parameters and removes the step-wise rule teacher for free growth.
Table~\ref{tab:ar} reports terminal validity and the Emb F1 probe at the target
size.  Legal and Net use distinct live-state gates, so their validity values must
be interpreted separately.

\paragraph{Protocol boundary.}
The training phase supplies a graph-family legality signal at the training
scale.  The evaluation phase fixes the learned parameters, increases the target
size, and does not query a rule teacher after each expansion.  A Legal gate keeps
states satisfying the declared predicate, whereas a Net gate uses the learned
network score to select live states.  The protocol records the target size,
number of samples, maximum live-state capacity, gate type, and random seed.
These details matter because a high terminal validity can otherwise be caused by
filtering, beam capacity, or a teacher that remains active at test time.

\subsection{Reproducibility, cost, and limits}
The released package provides pretrained checkpoints, an end-to-end toy test,
and checks for OCB, HiGraph, and planar metadata.  Link training samples point
pairs rather than materializing a dense adjacency prediction.  This describes
the implementation cost but is not an efficiency claim.  Before submission, we
will report parameter count, effective optimization steps, wall time,
per-step time, peak memory, and inference time for each primary graph family.

The present evidence has three boundaries.  First, all task instances are
independently trained.  Second, the recovery target only covers declared links
and node content; an application that requires edge attributes needs an explicit
edge decoder and target.  Third, terminal validity depends on the graph-family
predicate, live-state capacity, and gate.  The generation results should not be
read as evidence for untested graph rules.

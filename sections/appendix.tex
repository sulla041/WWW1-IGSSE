\section{Submission Evidence Checklist}
\label{app:checklist}

The following evidence is required before submission and is intentionally not
replaced by proxy metrics in the main text.
\begin{itemize}
  \item A direct recovery table with pair-decoder link F1/AUC/AP and content
  decoder feature R$^2$/cosine for every primary graph family.
  \item A cost table with parameter count, optimization steps, wall time,
  per-step time, peak memory, and inference time.
  \item Distribution-quality evidence for autoregression: degree or clustering
  statistics, a specified MMD when applicable, uniqueness, novelty, and
  node-order sensitivity.
\end{itemize}

\section{Reproducibility}
The source package documents commands for checkpoint evaluation and smoke tests.
The anonymous release must remove local paths and author-identifying metadata
before it is linked from the submission.

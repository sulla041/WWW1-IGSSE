Graphs are a natural representation for complex relations and rich information
on the Web, supporting recommendation, citation analysis, collaboration
modeling, program reasoning, electronic design, molecular prediction, and social
network analysis.  Effective graph modeling must capture local node attributes,
adjacency patterns, and global topological regularities that shape downstream
tasks.  The prevailing graph neural network paradigm propagates messages along
observed edges and stacks neighborhood aggregation layers to produce node or
graph states.  However, oversmoothing, Weisfeiler Leman expressivity limits, and
structural compression can weaken the graph information available in the learned
hidden state.  This motivates a representation that fits neural hidden spaces
while retaining enough graph information to model hidden topological regularities
for downstream tasks.

We propose \method{} (Invertible Graph Set Space Embedding), a recoverable set
space embedding for attributed graphs.  \method{} maps node attributes to an
attribute only content embedding, then writes structural deviations through a
feature and structure deviation encoder that combines local graph neighborhoods,
global structural bias, and relation conditions.  The resulting point set, with
rows corresponding to graph nodes, becomes an approximate equivalence class of
the graph: single point decoding recovers node content, pair attention decoding
recovers relations between points, and downstream readers model points and point
pair relations.  After recovery training, the point set approximates the
original graph on the selected content and relation targets and converts graph modeling into neural set
modeling over vectors.  A set expansion module further supports rule preserving
autoregressive graph growth on the same representation interface.  We evaluate
\method{} on public datasets covering product purchase relations,
collaboration, citation, program, circuit, timing, molecular, and social graphs,
and on rule preserving growth for planar, chordal, and bipartite graphs.  Across
ten prediction comparisons, \method{} exceeds every listed competitive graph
modeling baseline, demonstrating strong feature prediction performance.  A WL
collision diagnostic shows that reconstruction trained point sets separate the
evaluated second order and third order WL collision graph pairs, and rule
preserving autoregressive generation shows that the framework captures global
graph regularities while improving over the message passing generation baselines
used in the comparison.  These results establish \method{} as an efficient,
trained-recoverable framework for graph embedding, downstream prediction, and
autoregressive graph modeling.

3 IGSSE

3.1 表示对象与符号

IGSSE 的算法主线由三部分组成。首先，模型把输入属性图映射为节点对应的点集；其次，内容解码器和关系解码器约束该点集成为图的近似等价表示；最后，下游读出器直接在点集上完成预测。整体目标单独写为：

\[
G=(V,E,\mathbf X)\xrightarrow{\operatorname{Enc}_{\theta}}\Hset=\{\mathbf h_i\}_{i=1}^{n}\xrightarrow{R_{\phi}}\widehat Y .
\]

其中输入图表示带属性图，点集表示节点对应表示，下游预测由读出器产生。该路径由局部计算定义：每个点从自身内容坐标开始，结构更新来自关系选择的源状态写入，下游预测读取同一个受到恢复损失约束的点集。
输入图具有节点、边和节点属性，邻接矩阵作为关系恢复目标，节点数为 $n$。任务标签可以是节点类别、图标签或连续目标。嵌入路径使用图属性与关系，IGSSE 产生一个 $n$ 行、$d$ 列的点集矩阵，其中第 $i$ 行仍然与节点 $i$ 对应。这种行对应关系是核心：内容解码器从单个点读取节点内容目标，关系解码器从一对点读取图关系。

恢复目标包含邻接目标和内容目标：

\[
T(G)=(\mathbf A,\mathbf C),\qquad
\mathbf C=\operatorname{sg}(\operatorname{Enc}_{X}(\mathbf X)).
\]

其中停止梯度算子阻断内容目标上的梯度。某些配置也可以恢复标准化原始特征目标。无论哪种配置，任务标签都不进入恢复目标。停止梯度的编码目标防止内容解码器通过目标编码器形成捷径式重构。本文用 decoder point set 表示由内容和关系解码器验证的最终状态，用 task point set 表示最终状态或跳连拼接后的读出输入。二者的区分使读出器可以选择更适合预测的状态，同时恢复解码器始终检查固定的表示对象，从而让点集在任务头之前稳定承载图内容和关系。

符号表给出关键量含义：输入属性图由节点、边和属性构成，邻接目标表示关系恢复目标，内容目标表示内容恢复目标，原始内容坐标表示节点进入结构写入前的点状态，结构偏差表示写入节点的关系修正，最终点表示融合后的点状态，点集表示用于恢复和下游建模的表示对象，关系解码器与内容解码器分别恢复边关系和节点内容，下游读出器产生任务预测。

核心路径与图中流程对应。算法首先形成原始内容坐标。随后，基于可训练投影矩阵得到 query、key 和 value，并由全局注意力场形成上下文化源状态。观测邻接再为每个目标节点选择可写入的源状态，这些源状态的加权和形成结构偏差。最后，原始内容坐标与结构偏差融合，得到最终点。内容坐标记录不读取关系时可用的信息，全局场计算可复用源状态，邻接决定源状态写入位置，因此内容坐标和结构偏差分别承担内容基线和关系修正作用。后续层用前一层点状态替代初始内容坐标并重复该路径。

3.2 嵌入为点集

嵌入阶段在每一层重复同一个两部分操作。第 $\ell$ 层中，原始坐标表示即将接收结构写入的点状态。第一层中，该坐标由属性编码器产生：

\[
\mathbf h_{o,i}^{(0)}=\operatorname{Enc}_X(\mathbf x_i).
\]

后续层中，前一层融合后的点作为新的原始坐标。属性编码器只处理节点属性，不访问边集合，因此它为后续结构修正和内容恢复目标提供显式内容参照。实现时，属性编码器是带层归一化的共享 MLP，输出维度等于模型宽度。默认内容目标由停止梯度的同一属性编码器产生，使内容恢复依赖输入属性，同时防止解码器更新目标编码器。

原始内容坐标是每个点的内容载体。层内 query、key 和 value 都由原始坐标经过可训练投影得到，最终融合也保留从该坐标到最终点的残差路径。写入集合包含目标点自身以及与目标点相连的源点：

\[
N_A(i)=\{s:(s,i)\in E\}\cup\{i\}.
\]

对每个注意力头，投影产生 query、key 和 value：

\[
\mathbf q_i^{(m)}=\mathbf W_Q^{(m)}\mathbf h_{o,i}^{(\ell)},\quad
\mathbf k_i^{(m)}=\mathbf W_K^{(m)}\mathbf h_{o,i}^{(\ell)},\quad
\mathbf v_i^{(m)}=\mathbf W_V^{(m)}\mathbf h_{o,i}^{(\ell)}.
\]

缩放内积先产生全局注意力分数，再对所有点归一化得到上下文化源状态：

\[
\mathbf u_s^{(m)}=\sum_j\operatorname{softmax}_j\!\left(
\frac{(\mathbf q_s^{(m)})^\top\mathbf k_j^{(m)}}{\sqrt{d_h}}\right)
\mathbf v_j^{(m)}.
\]

这样，长程属性上下文在拓扑选择写入位置之前已经被编码进源状态。

噪声课程只作为训练阶段的结构写入调节。噪声网络 $\psi$ 接收平均头能量和归一化训练进度 $u$，预测边相关扰动尺度，并在训练阶段向关系分数加入调度噪声。评估时使用干净关系分数。survival 项防止训练噪声尺度在噪声阶段平凡消失，使结构写入在训练过程中保持有效扰动。自环项保证孤立点仍然保持 live 状态，写入集合上的 softmax 使每个目标点的输入强度可控。

结构偏差 $\mathbf o_i$ 是写入原始坐标的关系修正。对每个目标，在 $N_A(i)$ 上的 softmax 给出 $\alpha_{si}^{(m)}$，投影后的多头和定义 $\mathbf o_i^{(\ell)}$。这一计算表示邻接选择的全局源状态如何被写入点集。

融合为最终点。点状态由原始坐标和结构偏差相加得到，再经过归一化和前馈更新产生层输出：

\[
\mathbf h_i^{(\ell)}=\Phi\!\left(\mathbf h_{o,i}^{(\ell)}+\operatorname{Dropout}(\mathbf o_i^{(\ell)})\right).
\]

经过全部层后，最终点矩阵用于恢复：

\[
\Hset_{\mathrm{dec}}=\mathbf H^{(L)}.
\]

节点任务可以使用该最终状态，也可以使用各层状态的跳连拼接。融合保留内容坐标作为残差主干，并把结构偏差作为加性修正，因此点集中同时保留属性参照和关系条件化信息。dropout 只作用在结构偏差上，用于正则化关系写入而不擦除内容坐标。

算法 1 使用与符号表一致的表格形式展示，并在左列给出逐行编号。输入为 $\mathbf X$、$E_{\mathrm{enc}}$ 和训练进度 $u$；输出为 $\Hset_{\mathrm{dec}}$、$\Hset_{\mathrm{task}}$ 和 $\overline\sigma$。编号行依次执行初始化、层循环、可训练投影、关系能量计算、全局源状态构造、写入 logits 构造、训练噪声注入、结构写入、原始坐标与结构偏差融合、下一层坐标更新、循环结束和返回。

3.3 点集的近似等价性

图恢复以 $\Hset$ 为建模对象。关系解码器从 $\Hset$ 中读取两个点，恢复二者之间是否存在图关系；内容解码器从 $\Hset$ 中读取一个点，恢复对应内容目标。二者共同使学习到的点集在所选恢复目标下成为图的近似等价类。

成对注意力关系解码器把最终点行投影为每个头对应的 query 和 key，对缩放内积打分，对无向关系的两个方向做对称化，并应用可学习尺度和偏置。对候选点对 $(i,j)$，得分 $s_{ij}$ 经 sigmoid 产生邻接预测 $\widehat A_{ij}$。链接损失对 $s_{ij}$ 和 $A_{ij}$ 施加二元交叉熵。关系解码器在缩放内积前使用归一化投影，使分数主要由角度兼容性和可学习全局尺度控制。无向图共享两个方向的恢复分数；有向图移除对称化操作。存在边属性时，额外的成对解码器在二元关系分数选出的候选点对上预测边属性。

伴随的点级内容解码器产生内容预测：

\[
\widehat{\mathbf C}=D_C(\Hset_{\mathrm{dec}}).
\]

内容损失测量预测内容与内容目标的均方误差。两个损失测量互补量：成对注意力评估点对的关系几何，内容解码器评估可从单个最终点解码的内容。二者的联合评估定义直接重构标准。

成对采样与目标卫生保证恢复目标清晰。物化每个非边没有必要，并且会在稀疏图上支配目标函数。每次更新时，首先将无向边规范为固定顺序，移除自环，并从完整输入图中抽取正样本。随后通过均匀提出两个不同节点、规范化点对顺序并拒绝已有正边来抽取等量负样本。默认正负样本数量相同；如果正样本数超过点对预算，则均匀抽取预算内正样本并抽取等量负样本；小图使用全部正样本。负采样器在固定拒绝预算后停止，使稠密图的实际点对数量保持显式。如果编码器中启用边 dropout，它只影响编码计算图；链接正样本仍来自未 dropout 的输入图。这一区分把输入扰动和重构目标变化分开。

内容目标也需要同样的边界。默认配置中，即使编码器接收输入扰动，内容恢复目标仍使用干净属性经过停止梯度后的属性编码结果。直接特征配置用标准化原始属性替代编码内容目标。两种变体都保持标签边界：任务标签只出现在训练 mask 上的预测损失中。该边界防止恢复路径观察下游任务需要预测的目标。

内容解码器是在 decoder point set 上逐点应用的层归一化 MLP。特征重构测量每个最终点中可解码的信息。其配置形式包含层归一化和非线性隐藏变换，输出维度等于目标维度。边属性使用读取两个端点的成对解码器和显式边属性损失。


3.4 基于点集的下游建模接口

所有下游任务都以 $\Hset$ 为建模对象。节点预测对点行应用共享读出器，图预测把集合池化为不变状态，图自回归建模先扩展点集再进行关系解码。这样，预测、恢复和增长都由同一个点集接口支撑。点预测使用共享 MLP 读取 $\Hset_{\mathrm{task}}$ 的每一行；图预测先由点分数得到 $\beta_i$，在图内归一化后加权池化为 $\mathbf g$，再交给图读出器。分类和回归根据任务选择相应预测损失，恢复损失继续附着在 $\Hset$ 上。

算法 2 同样使用带行号的表格形式描述基于 $\Hset$ 的下游预测。输入为 $\Hset_{\mathrm{task}}$、任务类型、读出器 $R$ 和 labels。编号行分别处理节点任务、图任务、训练标签上的预测损失，并返回预测分数和 $\mathcal L_{\mathrm{pred}}$。

对自回归图建模，扩展算子把当前集合映射为更大的集合，同一个关系解码器恢复扩展后的图。集合扩展从学习到的 proposal 中追加一个或多个 live points，并通过同一个集合接口更新已有点。关系解码器随后把扩展点集转换为候选边。训练使用图规则合法性信号监督候选转移；评估时固定参数产生自由增长 rollout，并报告终止有效性和关系嵌入探针。

算法 3 使用带行号的表格形式描述自回归图建模。输入为 $\Hset_0$、$\operatorname{StepSet}$、$D_A$、目标尺寸和 selector。编号行维护候选集合 $\mathcal B$，循环扩展每个候选点集，使用关系解码器得到扩展图，计算选择分数，更新候选集合，并返回终止图、有效性和关系探针指标。

3.5 端到端训练

每个下游任务都可以构造端到端训练目标，将任务监督与两类恢复损失聚合。预测损失只在训练标签上读取任务标签。链接损失和内容损失直接附着在 decoder point set 上，因此读出器学习任务时，点集仍然受到内容和关系恢复约束。联合目标为：

\[
\mathcal L=\sum_{t\in\{\mathrm{pred},\mathrm{link},\mathrm{feat},\mathrm{alive}\}}\lambda_t\mathcal L_t.
\]

其中 prediction 项监督下游任务，link 项监督关系恢复，feature 项监督内容恢复，alive 项保持训练噪声尺度活跃。默认设置中，prediction 和 link 权重为 1.0，feature 权重为 0.1，alive 权重为千分之一；模型宽度为 128，编码器深度为 3 层，注意力头数为 4，隐藏宽度为模型宽度的四倍，dropout 为 0.1；关系恢复每次更新最多抽取 4096 个正样本和等量负样本；优化器为 AdamW，学习率为千分之一，weight decay 为万分之一，梯度裁剪阈值为 1.0；噪声调度从 1 线性衰减到 0，使关系扰动在训练初期较强，并在验证和测试时消失。仅训练嵌入时关闭 prediction 项；任务训练时同时优化任务损失和恢复损失。

训练设置区分带噪训练状态、干净验证状态和测试状态。归一化训练进度只控制噪声退火；验证选择和测试评估使用未扰动关系能量。验证指标选择 checkpoint，测试划分只从所选 checkpoint 读取一次。分类任务使用训练标签上的交叉熵，回归任务根据数据集指标使用均方误差或平均绝对误差。恢复损失与任务损失在同一个 minibatch 上计算，干净验证阶段关闭关系噪声和 dropout。若某个数据集修改维度、深度、点对预算或优化器 schedule，则在对应实验设置中报告。

3 IGSSE

3.1 表示对象与符号

IGSSE 使用同一个点集作为嵌入、恢复和下游建模的共同对象。输入是属性图，包含节点集合、边集合和属性矩阵。编码器把该图映射为一个有 n 行、d 列的点集矩阵。第 i 行表示与第 i 个节点对应的点。

\[
G=(V,E,\mathbf X)\xrightarrow{\operatorname{Enc}_{\theta}}\Hset=\{\mathbf h_i\}_{i=1}^{n}\xrightarrow{R_{\phi}}\widehat Y .
\]

嵌入阶段把原始内容坐标和结构偏差组合成最终点。恢复阶段使用内容解码器从单个点恢复内容目标，使用关系解码器从点对恢复邻接目标。下游阶段使用读出器读取点集并产生预测。恢复目标为：

\[
T(G)=(\mathbf A,\mathbf C),\qquad
\mathbf C=\operatorname{sg}(\operatorname{Enc}_{X}(\mathbf X)).
\]

其中任务标签记为 Y，可以是节点标签、图标签或连续目标。因此，这组符号固定了一条数据流：编码器构造点集，恢复解码器规定点集必须保持的图信息，下游读出器消费同一个点集完成预测。符号表给出关键量含义：输入属性图由节点、边和属性构成，邻接目标表示关系恢复目标，内容目标表示内容恢复目标，原始内容坐标表示节点进入结构写入前的点状态，结构偏差表示写入节点的关系修正，最终点表示融合后的点状态，点集表示用于恢复和下游建模的表示对象，关系解码器与内容解码器分别恢复边关系和节点内容，下游读出器产生任务预测。

3.2 嵌入为点集

嵌入阶段按顺序计算三个量。首先，模型把节点属性映射为原始坐标，保持结构写入前的节点行对应关系。其次，模型形成全局结构偏置，并通过邻接选择写入分量，得到结构偏差。最后，模型把原始坐标和结构偏差融合成最终点，并堆叠为点集。数据流为：

\[
\mathbf h_{o,i}\quad\longrightarrow\quad \mathbf o_i\quad\longrightarrow\quad
\mathbf h_i\quad\longrightarrow\quad \Hset .
\]

原始坐标。该步骤的目标是构造进入结构写入的内容坐标。第 $\ell$ 层中，原始坐标表示关系信息加入前的点状态。第一层中，该坐标只由第 i 个节点的属性行产生：

\[
\mathbf h_{o,i}^{(0)}=\operatorname{Enc}_X(\mathbf x_i).
\]

后续层中，前一层融合后的点作为新的原始坐标。属性编码器是带层归一化的共享 MLP，输出维度等于模型宽度。原始坐标记录节点内容，是关系信息写入之前的点状态。该阶段的数据流保持行对应：第 i 个节点的输入行被映射为同一节点的点行，不读取边信息。因此，该步骤输出行对应的内容坐标矩阵，作为结构写入的输入。

当多个原始坐标相同或十分接近时，训练路径在注意力投影之前加入独立的零均值扰动：

\[
\widetilde{\mathbf h}_{o,i}^{(\ell)}=\mathbf h_{o,i}^{(\ell)}+
\sigma_i g(u)\boldsymbol\epsilon_i,\qquad
\boldsymbol\epsilon_i\sim\mathcal N(\mathbf 0,\mathbf I).
\]

扰动后的状态产生不同的 query、key 和 value，使全局结构偏置及邻接选择写入能够把初始重合的点推向不同方向。该扰动用于提供探索方向，不承担节点身份或结构标签的作用；其尺度沿嵌入过程调度，学习到的结构偏差随后由确定性编码路径使用。

扰动尺度由共享的噪声尺度网络产生。对每个入边和注意力头，先根据关系能量、归一化进度和轻量投影得到正值尺度，并限制在预设上界内；训练进度从 0 到 1 变化，调度函数取进度的剩余量。所有尺度的均值记为 $\bar\sigma$，用于生存辅助损失。

结构偏差。该步骤的目标是把关系信息转换为每个点上的加性偏差。计算过程先从当前内容坐标形成全局结构偏置，再由邻接决定哪些偏置分量写入到每个目标点。层内 query、key 和 value 都由扰动后的原始坐标经过可训练投影得到：

\[
\mathbf q_i^{(m)}=\mathbf W_Q^{(m)}\widetilde{\mathbf h}_{o,i}^{(\ell)},\quad
\mathbf k_i^{(m)}=\mathbf W_K^{(m)}\widetilde{\mathbf h}_{o,i}^{(\ell)},\quad
\mathbf v_i^{(m)}=\mathbf W_V^{(m)}\widetilde{\mathbf h}_{o,i}^{(\ell)}.
\]

缩放内积先产生全局注意力分数，再对所有点归一化得到全局结构偏置：

\[
\mathbf u_s^{(m)}=\sum_j\operatorname{softmax}_j\!\left(
\frac{(\mathbf q_s^{(m)})^\top\mathbf k_j^{(m)}}{\sqrt{d_h}}\right)
\mathbf v_j^{(m)}.
\]

query 和 key 投影决定哪些点在全局结构偏置中发生交互，value 投影决定这个偏置携带什么信息。由于该偏置随后会写入最终点集，恢复损失和预测损失的梯度会经过融合后的点反传到这三个投影矩阵。因此，全局结构偏置的注意力场会被训练成同时服务图恢复和下游读出的结构信息。

邻接为每个目标点定义写入集合：

\[
N_A(i)=\{s:(s,i)\in E\}\cup\{i\}.
\]

因此，结构偏置在写入前已经包含全局注意力信息，邻接只决定哪些偏置分量写入到目标点。对每个目标，在写入集合上的 softmax 给出写入权重，投影后的多头和定义结构偏差：

\[
\mathbf o_i^{(\ell)}=\Psi^{(\ell)}(\widetilde{\mathbf H}_o,\mathbf A)_i
=\mathbf W_O\Vert_m\sum_{s\in N_A(i)}\alpha_{si}^{(m)}\mathbf u_s^{(m)}.
\]

结构偏差是加入原始坐标的关系条件化修正，记结构写入算子为 $\Psi^{(\ell)}$。对目标点 $i$，邻接集合上的局部写入权重由关系能量归一化得到：

\[
\alpha_{si}^{(m)}=\frac{\exp(e_{si}^{(m)})}
{\sum_{r\in N_A(i)}\exp(e_{ri}^{(m)})},\qquad s\in N_A(i).
\]

自环项保证孤立点保持活跃，softmax 控制每个目标点的输入强度。上述状态扰动发生在投影之前，因此同时改变被写入的 value 和写入权重，使接近的点在嵌入过程中产生分离。确定性编码路径使用由这些分离状态学习得到的结构偏差。因此，该步骤输出与原始坐标同行对应的结构感知修正。

融合为最终点。该步骤的目标是把内容和结构合成为最终点表示。最终点由原始坐标和结构偏差相加得到，对结构偏差分支使用 dropout 后，再经过归一化和前馈更新产生层输出：

\[
\mathbf h_i^{(\ell)}=\Phi\!\left(\mathbf h_{o,i}^{(\ell)}+\operatorname{Dropout}(\mathbf o_i^{(\ell)})\right).
\]

融合后的点作为下一层原始坐标。经过全部层后，堆叠所有最终点得到用于恢复和下游读出的点集：

\[
\Hset_{\mathrm{dec}}=\mathbf H^{(L)}.
\]

任务状态由读出配置决定：启用 jump connection 时，将各层点状态拼接为 $\Hset_{\mathrm{task}}$；否则令 $\Hset_{\mathrm{task}}=\Hset_{\mathrm{dec}}$。因此，$\Hset_{\mathrm{dec}}$ 专门提供给恢复解码器，$\Hset_{\mathrm{task}}$ 提供给任务读出器。

因此，嵌入阶段的核心关系就是原始坐标加结构偏差并经过融合，得到节点对应点集，用于图恢复、预测和自回归图建模。该层的数据流是闭合的：一层输出矩阵成为下一层内容坐标矩阵，多层重复细化同一个节点对应点集。因此，该步骤在每一行输出最终点，并在图层级输出完整点集。

算法 1 使用与符号表一致的表格形式展示，并在左列给出逐行编号。输入为 $\mathbf X$、$E_{\mathrm{enc}}$ 和训练进度 $u$；输出为 $\Hset_{\mathrm{dec}}$、$\Hset_{\mathrm{task}}$ 和 $\overline\sigma$。编号行依次执行初始化、状态扰动、可训练投影、关系能量计算、全局结构偏置构造、写入 logits 构造、结构写入、原始坐标与结构偏差融合、下一层坐标更新、循环结束和返回。

3.3 点集的近似等价性

图恢复以 $\Hset$ 为建模对象。关系解码器从 $\Hset$ 中读取两个点，恢复二者之间是否存在图关系；内容解码器从 $\Hset$ 中读取一个点，恢复对应内容目标。训练后的两个解码器共同使点集在所选恢复目标下成为图的经验性近似等价类；该性质由恢复指标、Emb 和下游结果共同评价。

成对注意力关系解码器把最终点行投影为每个头对应的 query 和 key，对缩放内积打分，对无向关系的两个方向做对称化，并应用可学习尺度和偏置。对候选点对 $(i,j)$，得分 $s_{ij}$ 经 sigmoid 产生邻接预测 $\widehat A_{ij}$。链接损失对 $s_{ij}$ 和 $A_{ij}$ 施加二元交叉熵。该损失的梯度更新成对解码器投影、可学习尺度和偏置，并经过两个端点反传到产生点集的编码器参数。正样本提高端点投影之间的兼容性，负样本降低非边投影之间的兼容性。由于端点来自下游任务使用的同一个点集，链接恢复也会塑造下游预测使用的嵌入几何。关系解码器在缩放内积前使用归一化投影，使分数主要由角度兼容性和可学习全局尺度控制。无向图共享两个方向的恢复分数；有向图移除对称化操作。存在边属性时，额外的成对解码器在二元关系分数选出的候选点对上预测边属性。

伴随的点级内容解码器产生内容预测：

\[
\widehat{\mathbf C}=D_C(\Hset_{\mathrm{dec}}).
\]

内容损失测量预测内容与内容目标的均方误差。其梯度更新点级内容解码器和形成每个点的编码路径，使点在接收关系条件化结构偏差的同时保留内容坐标。两个损失测量互补量：成对注意力评估点对的关系几何，内容解码器评估可从单个最终点解码的内容。二者的联合评估定义直接重构标准。

成对采样与目标卫生保证恢复目标清晰。物化每个非边没有必要，并且会在稀疏图上支配目标函数。每次更新时，首先将无向边规范为固定顺序，移除自环，并从完整输入图中抽取正样本。随后通过均匀提出两个不同节点、规范化点对顺序并拒绝已有正边来抽取等量负样本。默认正负样本数量相同；如果正样本数超过点对预算，则均匀抽取预算内正样本并抽取等量负样本；小图使用全部正样本。负采样器在固定拒绝预算后停止，使稠密图的实际点对数量保持显式。如果编码器中启用边 dropout，它只影响编码计算图；链接正样本仍来自未 dropout 的输入图。这一区分把输入扰动和重构目标变化分开。

内容目标也需要同样的边界。默认配置中，即使编码器接收输入扰动，内容恢复目标仍使用干净属性经过停止梯度后的属性编码结果。直接特征配置用标准化原始属性替代编码内容目标。两种变体都保持标签边界：任务标签只出现在训练 mask 上的预测损失中。该边界防止恢复路径观察下游任务需要预测的目标。

内容解码器是在用于恢复的点集上逐点应用的层归一化 MLP。特征重构测量每个最终点中可解码的信息。其配置形式包含层归一化和非线性隐藏变换，输出维度等于目标维度。边属性使用读取两个端点的成对解码器和显式边属性损失。关系恢复约束点对几何，内容恢复约束单点信息，二者共同构成点集近似等价类的训练后证据。


3.4 基于点集的下游建模接口

所有下游任务都以 $\Hset$ 为建模对象。节点预测对点行应用共享读出器，图预测把集合池化为不变状态，图自回归建模先扩展点集再进行关系解码。这样，预测、恢复和增长都由同一个点集接口支撑。点预测使用共享 MLP 读取 $\Hset_{\mathrm{task}}$ 的每一行；图预测先由点分数得到 $\beta_i$，在图内归一化后加权池化为 $\mathbf g$，再交给图读出器。集合注意力读出器先为每个点计算标量分数，在图内归一化为权重，再用这些权重汇聚投影后的点值。任务损失会更新池化打分器、value 投影、图读出器以及产生点集的编码器参数。对图目标有用的点获得更大的池化权重，value 投影学习进入图状态的信息。分类和回归根据任务选择相应预测损失，恢复损失继续附着在 $\Hset$ 上。

算法 2 同样使用带行号的表格形式描述基于 $\Hset$ 的下游预测。输入为 $\Hset_{\mathrm{task}}$、任务类型、读出器 $R$ 和 labels。编号行分别处理节点任务、图任务、训练标签上的预测损失，并返回预测分数和 $\mathcal L_{\mathrm{pred}}$。

对自回归图建模，扩展算子把当前集合映射为更大的集合，同一个关系解码器恢复扩展后的图。集合扩展从学习到的 proposal 中追加一个或多个 live points，并通过同一个集合接口更新已有点。关系解码器随后把扩展点集转换为候选边。训练使用图规则合法性信号监督候选转移；rollout 过程中固定参数反复扩展 live set，并从当前点集解码关系。

算法 3 使用带行号的表格形式描述自回归图建模。输入为 $\Hset_0$、$\operatorname{StepSet}$、$D_A$、目标尺寸和 selector。编号行维护候选集合 $\mathcal B$，循环扩展每个候选点集，使用关系解码器得到扩展图，计算选择分数，更新候选集合，并返回终止点集和解码图。因此，点预测、图预测和自回归图建模都是同一个对象上的不同读出形式；任务头随输出类型变化，表示目标始终是同一个点集。

3.5 端到端优化

每个下游任务都可以构造端到端训练目标，将任务监督与两类恢复损失聚合。预测损失只在训练标签上读取任务标签。链接损失和内容损失直接附着在用于恢复的点集上，因此读出器学习任务时，点集仍然受到内容和关系恢复约束。联合目标为：

\[
\mathcal L=\lambda_{\mathrm{pred}}\mathcal L_{\mathrm{pred}}+
\lambda_l\mathcal L_l+\lambda_f\mathcal L_f+\lambda_e\mathcal L_e.
\]

其中 prediction 项监督下游任务，$\mathcal L_l$ 表示关系恢复 BCE，$\mathcal L_f$ 表示内容恢复 MSE，$\mathcal L_e$ 表示 $-\log(\max(\bar\sigma,\epsilon))$ 的生存项。联合目标通过同一个点集连接各个注意力机制：prediction 项更新节点读出器、集合注意力池化、图读出器、自回归选择器以及形成点集的编码器投影；$\mathcal L_l$ 更新成对注意力解码器并经过端点反传到嵌入投影；$\mathcal L_f$ 更新内容解码器和属性进入点集的路径；$\mathcal L_e$ 更新结构写入前的噪声尺度网络。默认设置中，prediction 和 link 权重为 1.0，feature 权重为 0.1，alive 权重为千分之一；模型宽度为 128，编码器深度为 3 层，注意力头数为 4，隐藏宽度为模型宽度的四倍，dropout 为 0.1；关系恢复每次更新最多抽取 4096 个正样本和等量负样本；优化器为 AdamW，学习率为千分之一，weight decay 为万分之一，梯度裁剪阈值为 1.0；状态扰动在嵌入过程中按训练进度调度，使初始接近的点获得分离方向。任务训练时同时优化任务损失和恢复损失。

归一化训练进度只控制噪声退火。分类任务使用训练标签上的交叉熵，回归任务根据数据集指标使用均方误差或平均绝对误差。恢复损失与任务损失在同一个 minibatch 上计算。训练目标由此在整个优化过程中把嵌入、恢复解码器和下游读出器耦合到同一个点集上。

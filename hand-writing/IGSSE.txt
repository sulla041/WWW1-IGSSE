3 IGSSE

3.1 表示对象与符号

IGSSE 的算法主线由三部分组成。第一，嵌入阶段把属性图映射为点集 $\Hset$，对每个节点先形成原始内容坐标 $\mathbf h_{o,i}$，再写入结构偏差 $\mathbf o_i$，二者融合得到最终点 $\mathbf h_i$。第二，图恢复阶段从 $\Hset$ 解码节点内容和点对关系，使可恢复性成为近似等价的保证。第三，下游任务阶段以 $\Hset$ 为建模对象，支持特征预测、图预测和图自回归建模。

设 $G=(V,E,\mathbf X)$ 为带属性图，邻接矩阵为 $\mathbf A$，节点数为 $n$。任务标签 $y$ 可以是节点类别、图标签或连续目标。嵌入路径使用图属性与关系，IGSSE 产生 $\Hset\in\mathbb R^{n\times d}$，其中第 $i$ 行仍然与节点 $i$ 对应。这种行对应关系是核心：内容解码器必须从一个点读取节点目标，关系解码器必须从一对点读取图关系。

我们区分嵌入目标和预测目标。恢复目标为 $T(G)=(\mathbf A,\mathbf C)$，其中 $\mathbf C=\operatorname{sg}(\operatorname{Enc}_{X}(\mathbf X))$，$\operatorname{sg}$ 表示停止梯度。某些配置也可以恢复标准化原始特征目标。无论哪种情况，标签都被排除在恢复目标之外。停止梯度的编码目标防止特征解码器通过目标编码器形成捷径式重构。本文用 $\Hset_{\mathrm{dec}}$ 表示由两个解码器验证的最终状态，用 $\Hset_{\mathrm{task}}$ 表示最终状态或跳连拼接后的读出输入。该分离在任务读出之前固定被恢复的表示对象。

符号表在正文中给出关键量的含义：$G=(V,E,\mathbf X)$ 表示输入属性图，$\mathbf A$ 表示邻接目标，$\mathbf C$ 表示内容恢复目标，$\mathbf h_{o,i}$ 表示节点 $i$ 的原始内容坐标，$\mathbf o_i$ 表示写入节点 $i$ 的结构偏差，$\mathbf h_i$ 表示融合后的最终点，$\Hset$ 表示用于恢复和下游建模的点集，$D_A$ 与 $D_C$ 分别表示关系解码器与内容解码器，$R$ 表示下游读出器。

核心路径对应。核心计算首先形成原始内容坐标 $\mathbf h_{o,i}$。全局 query、key、value 注意力把所有节点变成上下文化源状态，入边邻接再选择写入目标 $i$ 的源状态；其加权和形成结构偏差 $\mathbf o_i$。随后 $\mathbf h_{o,i}$ 与 $\mathbf o_i$ 相加形成融合状态，再由归一化和前馈映射产生 $\mathbf h_i$。这一过程正对应图中的内容编码、结构写入、图恢复和下游读出路径。后续层用前一层点状态替代 $\mathbf h_o$ 并重复该路径。

3.2 由内容坐标和结构偏差构造嵌入

嵌入阶段在每一层重复同一个两部分操作。第 $\ell$ 层中，$\mathbf h_{o,i}^{(\ell)}$ 表示即将接收结构写入的原始坐标。第一层中，该坐标由属性编码器产生；后续层中，$\mathbf h_{o,i}^{(\ell)}=\mathbf h_i^{(\ell-1)}$。属性编码器只处理节点属性，不访问 $E$，因此它为后续结构修正和内容恢复目标提供显式内容参照。这里保留原始内容坐标公式作为第一条关键公式。

原始内容坐标 $\mathbf h_{o,i}$。该坐标是每个点的内容载体。层内的 query、key 和 value 投影都从 $\mathbf h_{o,i}^{(\ell)}$ 计算，最终融合也保留从该坐标到 $\mathbf h_i^{(\ell)}$ 的直接残差路径。多头投影先产生全局注意力场，再得到上下文化源状态 $\mathbf u_s$。邻接为每个目标 $i$ 定义写入集合 $N_A(i)=\{s:(s,i)\in E\}\cup\{i\}$，用于决定哪些源状态被写入目标点。

噪声课程。噪声网络 $\psi$ 接收平均头能量和归一化训练进度 $u$，预测边相关扰动尺度，并在训练阶段向关系分数加入调度噪声。评估时使用干净关系分数。该滤波器只解释图中结构写入阶段的训练调节，不再展开为额外公式。

结构偏差 $\mathbf o_i$。该偏差是写入原始坐标的关系修正。对每个目标，在 $N_A(i)$ 上的 softmax 给出 $\alpha_{si}^{(m)}$，投影后的多头和定义 $\mathbf o_i^{(\ell)}$。该公式是嵌入部分第二条关键公式，表示邻接选择的全局源状态如何被写入点集。

融合为 $\mathbf h_i$。点状态由原始坐标和结构偏差相加得到，随后经过归一化和前馈映射产生 $\mathbf h_i^{(\ell)}$。正文只保留这个融合核心公式。经过 $L$ 层后，$\Hset_{\mathrm{dec}}=\{\mathbf h_i^{(L)}\}_{i=1}^{n}$ 用于恢复；节点任务可以使用该最终状态，也可以使用各层状态的跳连拼接。

算法 1：点集嵌入。表格形式如下：Input 为 $\mathbf X,E_{\mathrm{enc}},u$；Output 为 $\Hset_{\mathrm{dec}},\Hset_{\mathrm{task}},\overline\sigma$；Init 执行 $\mathbf h_{o,i}^{(0)}\leftarrow\operatorname{Enc}_X(\mathbf x_i)$；for $\ell$ 执行 $(\mathbf q_i,\mathbf k_i,\mathbf v_i)\leftarrow\operatorname{Proj}(\mathbf h_{o,i}^{(\ell)})$、$e_{si}\leftarrow\operatorname{Energy}(\mathbf q_s,\mathbf k_i)$、$\mathbf u_s\leftarrow\operatorname{GlobalAttn}(e_{s:},\mathbf v)$、$\alpha_{si}\leftarrow\operatorname{Softmax}_{s\in N_A(i)}(e_{si})$、$\mathbf o_i^{(\ell)}\leftarrow\operatorname{Write}(\alpha_{:i},\mathbf u)$；if train 执行 $e_{si}\leftarrow e_{si}+\sigma_{si}g(u)\epsilon_{si}$；随后执行 $\mathbf r_i^{(\ell)}\leftarrow\mathbf h_{o,i}^{(\ell)}+\mathbf o_i^{(\ell)}$ 和 $\mathbf h_i^{(\ell)}\leftarrow\operatorname{FFN}(\operatorname{LN}(\mathbf r_i^{(\ell)}))$；return $\Hset_{\mathrm{dec}},\Hset_{\mathrm{task}},\overline\sigma$。

3.3 从点集恢复图

图恢复以 $\Hset$ 为建模对象。关系解码器从 $\Hset$ 中读取两个点，恢复二者之间是否存在图关系；内容解码器从 $\Hset$ 中读取一个点，恢复对应内容目标。二者共同使学习到的点集在所选恢复目标下成为图的近似等价类。

成对注意力关系解码器把最终点行投影为每个头对应的 query 和 key，对缩放内积打分，对无向关系的两个方向做对称化，并应用可学习尺度和偏置。对候选点对 $(i,j)$，正文只保留得分和邻接预测的核心公式；链接损失用文字说明。成对注意力读取最终点集；由于点行、query 和 key 会一起置换，所以该算子保持等变性。

伴随的点级内容解码器只保留内容预测公式，内容损失用文字说明。两个损失测量互补量：成对注意力评估点对的关系几何，$D_C$ 评估可从单个最终点解码的内容。二者的联合评估定义直接重构标准。

成对采样与目标卫生。物化每个非边没有必要，并且会在稀疏图上支配目标函数。每次更新时，首先将无向边规范为 $s<i$，移除自环，并从完整输入图中抽取正样本。随后通过均匀提出 $a\neq b$、规范化 $(a,b)$ 并拒绝 $E^+$ 中的点对来抽取等量负样本。负采样器在固定拒绝预算后停止，使稠密图的实际点对数量保持显式。如果编码器中启用边 dropout，它只影响计算图 $E_{\mathrm{enc}}$；链接正样本仍来自未 dropout 的输入图。这一区分把输入扰动和重构目标变化分开。成对注意力因此学习在扰动下构造的点集是否仍能区分目标关系。

内容目标也需要同样的卫生要求。默认配置中，即使编码器接收输入扰动，$\mathbf C=\operatorname{sg}(\operatorname{Enc}_X(\mathbf X))$ 仍使用干净属性。直接特征配置用标准化 $\mathbf X$ 替代 $\mathbf C$。两种变体都保持标签边界：$y$ 只出现在训练 mask 上的 $\mathcal L_{\mathrm{pred}}$ 中。该边界防止恢复路径观察下游任务需要预测的目标。

内容解码器是在 $\Hset_{\mathrm{dec}}$ 上逐点应用的层归一化 MLP。特征重构测量每个最终点中可解码的信息。其配置形式包含层归一化和非线性隐藏变换，输出维度等于目标维度。边属性使用成对解码器 $D_E(\mathbf h_i,\mathbf h_j)$ 和显式边属性损失。

3.4 训练日程与评估设置

优化日程分离三个容易混淆的量：训练时的带噪编码器状态、验证和测试时的干净确定性状态，以及只在训练样本上可见的任务标签。归一化训练进度只用于控制噪声退火，不再作为核心算法公式展开。之后的更新以及所有选择过程都使用未扰动关系能量。梯度裁剪限制联合更新，验证指标选择 checkpoint。测试划分只从所选 checkpoint 读取一次。嵌入维度、编码器深度、头数、隐藏宽度、dropout、优化器设置、损失权重和点对预算都作为实验配置处理，并在对应实验设置中报告。

嵌入探针测量标准化结构特征是否能从学习状态预测链接。直接恢复指标评估 $D_A$ 和 $D_C$。本文在每个点预测或集合预测比较之前分别报告这些互补指标。

3.5 损失附着点与梯度路径

联合目标公式有四个不同附着点。预测项监督任务读出器。链接项通过成对注意力和最终点集传递梯度。特征项通过内容解码器和最终点集传递梯度，目标编码器停止梯度。survival 项到达尺度网络和注意力能量路径。关系几何、节点内容、任务相关性和训练滤波器分别接收信号。$\mathcal L_{\mathrm{pred}}$ 在训练 mask 上读取 $y$；其余三项使用图信息。

对仅嵌入训练，预测项被关闭，表示项只使用图恢复目标训练点集。任务运行恢复 $\mathcal L_{pred}$ 并保留其他项。该日程明确了两种实验模式：表示训练单独评估点集，联合任务运行在保持信息目标激活的同时评估表示和读出器系统。

3.6 基于点集的下游建模接口

所有下游任务都以 $\Hset$ 为建模对象。节点预测对点行应用共享读出器，图预测把集合池化为不变状态，图自回归建模先扩展点集再进行关系解码。这样，预测、恢复和增长都由同一个点集接口支撑。图任务保留注意力池化公式，其中 $\beta_i$ 在图内归一化。分类和回归根据任务选择相应预测损失，恢复损失继续附着在 $\Hset$ 上。

算法 2：基于 $\Hset$ 的下游预测。表格形式如下：Input 为 $\Hset_{\mathrm{task}}$、任务类型、读出器 $R$ 和 labels；if node 执行 $\widehat{\mathbf y}_i\leftarrow R_{\mathrm{node}}(\mathbf h_i)$；if graph 执行 $\mathbf g\leftarrow\operatorname{Pool}(\Hset_{\mathrm{task}})$ 和 $\widehat{\mathbf y}_G\leftarrow R_{\mathrm{graph}}(\mathbf g)$；loss 执行 $\mathcal L_{\mathrm{pred}}\leftarrow\operatorname{TaskLoss}(\widehat{\mathbf y},y)$，并且只作用于训练标签；return prediction scores 和 $\mathcal L_{\mathrm{pred}}$。

对自回归图建模，扩展算子把当前集合映射为更大的集合，同一个关系解码器恢复扩展后的图。该公式是下游与生成部分第二条关键公式。训练使用图规则合法性信号监督候选转移；评估时固定参数产生自由增长 rollout，并报告终止有效性和关系嵌入探针。

算法 3：自回归图建模。表格形式如下：Input 为 $\Hset_0,\operatorname{StepSet},D_A$、目标尺寸和 selector；Init 执行 $\mathcal B\leftarrow\{\Hset_0\}$；while active 执行 $\mathcal C\leftarrow\emptyset$；for $\Hset_s\in\mathcal B$ 执行 $\Hset_{s+1}\leftarrow\operatorname{StepSet}(\Hset_s,\boldsymbol\epsilon_s)$、$\widehat E_{s+1}\leftarrow D_A(\Hset_{s+1})$、$\operatorname{score}\leftarrow\operatorname{SelectScore}(\widehat E_{s+1})$、$\mathcal C\leftarrow\mathcal C\cup\{(\Hset_{s+1},\operatorname{score})\}$；update 执行 $\mathcal B\leftarrow\operatorname{Select}(\mathcal C)$；return terminal graphs、validity 和 relation probe metrics。

3.7 对称性与目标

共享点映射和关系打分保持预期的置换结构。对一致节点置换 $\mathbf P$，编码器、关系解码器和池化满足同一个置换等变/不变关系。

为什么对称性成立。属性映射在行之间共享，因此与节点置换可交换。对固定目标，置换入边顺序会同时置换 softmax 参数和值，同时保持加权和不变。逐点应用的残差映射、层归一化和前馈层随后通过编码层归纳保持行对应关系。成对注意力同时接收两个点行，因此在两个邻接轴上共同变换；注意力池化同时置换权重和值，使求和保持不变。该论证假设所有边 dropout 和噪声样本都与图一致置换。

恢复含义。令 $D$ 为确定性解码器，$d_T$ 为目标空间上的距离。如果在评估域上恢复误差有界，则两个具有相同表示的图 $G_1,G_2$ 的目标距离也被恢复容差控制。两个目标都处在同一解码表示的恢复容差内，因此结论来自三角不等式。该表述解释了为什么直接恢复指标重要：它们限制了共享嵌入能够合并多少输入信息。精确反演、额外边属性和图同构各自需要自己的目标与评估指标。

每个任务实例联合优化上文给出的目标函数，其中 $\mathcal L_{\mathrm{alive}}=-\log(\max(\overline\sigma,\epsilon_{\mathrm{alive}}))$ 使学习到的训练噪声尺度保持活跃。预测损失只访问训练标签。恢复项在任务模式中保持激活，在读出器学习任务的同时保持嵌入下限。

计算边界。编码器只在 $E_{\mathrm{enc}}$ 上聚合，因此其层成本在头数和隐藏维度之外对编码边数线性。关系训练使用采样点对，而完整恢复评估可能打分更大的指定点对集合。集合注意力和无限制成对解码可能随 live point 数量二次增长。因此，我们把采样点对训练、分块解码和 live state 容量作为所报告图规模的显式评估设置。实验报告任务准确率和有效性；测量时间与内存仍是单独的证据要求。

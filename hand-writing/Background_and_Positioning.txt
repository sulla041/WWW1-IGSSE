2 Related Work

IGSSE 同时连接图算法、图学习局限性、近年扩大图交互范围的探索、等价类视角和神经集合建模。这些研究线索说明，图模型既需要更丰富的交互模式，也需要学习状态在任务读出前保持可恢复性；它们共同引出本文把点集作为下游建模中可恢复图代表的做法。

图表示学习算法。图表示学习从随机游走嵌入、邻域聚合逐步发展到注意力、传播、状态空间和集合建模。DeepWalk 和 node2vec 通过采样图游走学习保持邻近性的节点向量。消息传递神经网络随后使局部聚合成为主流神经图算法：图卷积、归纳式邻居采样、图注意力和表达性聚合函数分别服务于半监督节点预测、归纳学习和图预测任务。APPNP 通过 personalized PageRank 分离预测与传播。Graph Mamba 使用选择性状态空间建模，在由图产生的 token 顺序上捕捉长程依赖。这些算法构成了 Web 推荐、引文分析、程序推理、电子设计和科学图预测中常用的图学习工具箱。

图算法的已知局限。上述算法具有明确的结构局限。反复邻域平均会使节点状态随深度增加而趋同，形成深层图神经网络中的过平滑。消息传递模板的表达能力也受到一阶 Weisfeiler Leman 测试边界限制，而高阶变体会增加状态维度和计算成本。长程依赖带来另一类瓶颈：来自大量远距离节点的信息需要沿图中狭窄割压缩进固定宽度状态，这一现象被称为过压缩，并与图曲率和拓扑瓶颈相关。Graph Mamba 等长程图模型通过图序列和选择性状态空间降低局部性，但学习状态仍需要显式保证，使图内容和关系在任务读出前保持可恢复。这些局限说明，仅依靠任务监督隐状态不足以保证图内容和关系在读出前被完整保留。

近两年的探索与剩余问题。近年工作沿多条路线推进。Graph Mamba 等图状态空间模型使用选择性序列建模，在由图产生的 token 顺序上捕捉长程依赖。图重连方法通过改变连边来改善信息流；locality aware rewiring 明确平衡降低过压缩、保持图局部性和保持稀疏性。NeuralWalker 将随机游走序列与局部消息传递结合，使序列模型能够承载长程图信息。这些进展提高了交互范围和效率，但仍留下一个核心表示问题：学习状态如何在任务读出前保持图内容和关系。IGSSE 通过把可恢复性作为近似等价的保证来回答这一问题。

等价类与图表示。等价类为用一个代表对象替代原对象提供数学语言，前提是该代表保持研究目标所需的量。在图学习中，同构关系把具有相同标记结构的图划分为等价类，图规范化则为这类等价类选择代表。近年工作重新研究了图规范化在图表示学习中的作用，并分析了规范代表带来的表达能力和稳定性权衡。Graph as Point Set 进一步表明，图可以被转换为保持图信息的独立点集合，并交给集合编码器处理。IGSSE 沿用这一数学思想，并通过可恢复性定义近似等价关系：如果内容解码器和关系解码器能够恢复预定义的内容目标和邻接目标，则该点集可以作为下游建模使用的图代表。

集合建模算法。集合建模提供了图转化后的神经接口。Deep Sets 通过共享元素映射和不变聚合刻画置换不变集合函数。Set Transformer 用集合元素之间的注意力扩展这一接口，并通过诱导点注意力降低自注意力成本。Graph as Point Set 基于这一路线，用集合编码器处理由图转换而来的对象。IGSSE 继承相同的置换原则，同时保持点行与图节点的对应关系，从点对中解码关系，并用特征和链接可恢复性保证下游预测和图自回归建模所消费的近似等价关系。综合这些研究线索，IGSSE 采用的路线是：先把图映射为节点对应点集，再用内容和关系恢复使该点集成为近似等价类，最后让所有下游读出器作用于同一个集合对象。

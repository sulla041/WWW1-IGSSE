4 Experiments

实验部分围绕四个互补实验展开。第一，特征预测主实验检验可恢复点集是否能支持 Web 关系、程序、电路、时序、分子和社会图上的监督图学习。第二，自回归实验检验同一个集合对象能否在图规则监督下进行扩展。第三，消融实验分离恢复、结构偏差、训练扰动和集合读出的贡献。第四，WL 碰撞实验检验经过恢复训练的点集是否能区分受控的非同构图对。所有实验中，每个数据集训练自己的编码器、恢复解码器和任务读出器；验证指标选择 checkpoint，测试划分报告最终指标。

4.1 特征预测主实验

主实验在匹配数据划分、输入属性和任务指标下比较 IGSSE 与图学习基线。数据集覆盖四类图语义。Amazon Photo、Coauthor CS 和 Cora 分别表示产品购买、学术协作和引文关系。HiGraph 评估用于恶意软件分析的层次程序图。OCB 和 TimingPredict 评估电路连通性和布线前时序预测。AIDS 和 IMDB 提供分子图和社会图基准。这些数据集检验点集在标签位于节点、图或连续属性上时是否仍然有效。

基线按计算方式分组。MLP 只使用属性，不使用图结构。GCN、GraphSAGE、GAT 和 GIN 分别表示邻域聚合、归纳式采样、邻域注意力和表达性聚合。APPNP 测试先预测再通过 personalized PageRank 传播。Graph Mamba 测试近年的长程序列式图建模机制。PST 测试图到点集的路线。IGSSE 则把学习到的点集送入对应的点读出器或集合读出器。表 1 总结主实验。

表 1：特征预测主实验。表中列出 Web 关系图、程序图、电路与时序图、分子与社会图四类设置；每类设置给出对应数据集内容、比较方法和指标。Web 关系图使用 Amazon Photo、Coauthor CS 和 Cora；程序图使用 HiGraph；电路与时序图使用 OCB 和 TimingPredict；分子与社会图使用 AIDS 和 IMDB。比较方法包括 MLP、GCN、GraphSAGE、GAT、GIN、APPNP、Graph Mamba、PST 和 IGSSE。指标根据任务使用 accuracy、F1、回归指标或分类指标。

该实验是主要任务效用测试。表中性能提升表示，在相同划分和输入约定下，IGSSE 产生的点集能够支持对应监督预测目标。

4.2 自回归图建模

自回归实验在预测使用的同一表示接口上评估图增长。训练阶段在训练尺寸上提供图规则合法性信号。rollout 阶段，学习到的集合扩展算子追加新的 live points，更新当前点集，并使用关系解码器恢复候选边。评估记录终止有效性、目标尺寸、采样图数量、live state 容量、选择规则和随机种子。

图规则包括平面图、弦图和二部图谓词。平面图检验增长是否保持全局可嵌入约束；弦图检验生成图是否满足所需的环结构；二部图检验 live state 是否保持二分关系约束。比较方法包括 GraphRNN、GRAN、GraphVAE、GraphAF、score based graph generation 和 DiGress，分别代表循环式、注意力式、变分式、流式、score based 和 diffusion based 图生成。表 2 总结图增长设置。

表 2：自回归图建模实验。表中列出 planar、chordal、bipartite 和 selection rule 四行。前三行分别说明需要保持的图规则、比较的生成方法和有效性及恢复指标。selection rule 行区分 Legal selection 与 network selection，前者保留满足规则谓词的状态，后者使用学习到的网络分数选择 live states。指标包括 terminal validity、target size 和 recovery F1/AUC/AP。

该实验检验图恢复和集合扩展是否能够共享同一个点集。终止有效性评估最终解码图是否满足规则，关系恢复指标评估扩展后的点集是否仍然支持图解码。

4.3 消融实验

消融实验隔离 IGSSE 中哪些部分解释任务效用和可恢复性。完整模型使用内容编码、结构偏差写入、关系恢复、内容恢复、训练扰动和集合读出。每个消融变体在保持数据划分和指标不变的情况下移除或替换一个组件。目标是区分观察到的行为来自可恢复性、结构写入、训练扰动还是下游读出。

表 3 定义消融变体。No relation recovery 移除点对关系解码损失，检验点对可恢复性的作用。No content recovery 移除单点内容解码损失，检验结构写入后内容保持是否重要。No structural deviation 保留属性路径但移除关系条件化修正。No perturbation 移除训练中的调度写入噪声。Frozen point set 阻止任务损失更新编码器。Simplified reader 用更简单的读出器替代集合注意力池化。

表 3：消融实验。表中列出 Full IGSSE、No relation recovery、No content recovery、No structural deviation、No perturbation、Frozen point set 和 Simplified reader。每一行说明被修改的组件以及测量的效应，包括点对可恢复性、内容保持、结构写入、相似点分离、端到端任务适配和集合级聚合。

消融表按方向解释。任务指标下降衡量任务效用，链接或内容恢复下降衡量点集是否仍能在所选恢复目标下作为近似等价类。

4.4 WL 碰撞实验

WL 碰撞实验在受控非同构图对上评估表示分离。Weisfeiler Leman 层级为邻域聚合和高阶测试提供表达能力参照。BREC 提供 Basic、Regular、Extension、CFI、Four Vertex 和 Distance Regular 分层图对，用于暴露不同层次的 realized graph neural network expressiveness。对每个图对，IGSSE 只使用恢复目标训练，并在一致节点置换下解码两个图。

实验把恢复训练后的 IGSSE 与标准邻域聚合和受高阶 WL 启发的基线预期行为进行比较。分离通过重构图差异、关系 F1/AUC/AP 和置换偏差衡量。表 4 总结 WL 诊断。

表 4：WL 碰撞实验。表中列出 Basic、Regular、Extension 和 CFI 四类分层。Basic 包含按一阶 WL 行为分组的非同构图对；Regular 包含正则图、强正则图、Four Vertex 和 Distance Regular 图对；Extension 包含用于区分一阶和高阶测试之间细粒度能力的图对；CFI 包含具有较高 WL 难度的 Cai Furer Immerman 风格图对。比较方法包括邻域聚合、高阶 WL 启发基线和 IGSSE。指标为 separation 和 recovery。

该实验闭合证据链。主实验衡量监督任务效用，自回归实验衡量图增长，消融实验归因组件，WL 碰撞实验检验恢复训练点集是否能够在标准邻域聚合范围之外区分受控图对。

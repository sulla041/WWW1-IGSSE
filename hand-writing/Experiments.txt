4 Experiments

4.1 问题与设置

我们提出六个问题：（Q1）学习到的点集是否保留链接和节点内容；（Q2）它是否支持 Web 关系任务；（Q3）哪些编码器和读出组件解释任务效用；（Q4）经过图规则监督后，集合状态能否在训练规模之外自由增长；（Q5）图语义和输出层级如何影响结果；（Q6）在按一阶、二阶和三阶 WL 测试分层的非同构图对上，学习到的点集签名会在哪里发生碰撞。每个数据集训练自己的编码器、解码器和头。验证指标选择 checkpoint，测试划分报告结果。每个任务实例都在固定数据划分、输入约定和指标下学习专用表示与读出器。

列出的基线包括 MLP、GCN、GraphSAGE、GAT、GIN、APPNP、SGFormer、Polynormer、Graph-Mamba 和 PST。每一行固定输入约定、划分和主指标。Emb 列报告结构可分性，而成对解码器和内容解码器报告直接恢复。camera ready 的恢复表会为每个主要图规则设置报告链接 F1、AUC、AP 和特征 R$^2$/cosine，并同时报告优化步数和墙钟时间。

基线匹配。预测比较在每一行内使用相同划分、输入属性和任务指标。MLP 测试仅属性输入。GCN、GraphSAGE、GAT 和 GIN 表示邻域聚合；APPNP、SGFormer、Polynormer 和 Graph-Mamba 加入不同传播或长程机制；PST 测试图到集合路线。该比较回答行级问题：被评估的 IGSSE 配置是否在该评估设置下改善任务指标。

4.2 匹配预测比较

冻结的比较记录对每个任务比较最强列出基线和 IGSSE。IGSSE 在全部十个匹配比较行中超过列出的比较集合。结果覆盖购买关系、协作、引文、程序、电路、时序、分子和社会图设置。该表述只作用于该记录：它适用于工作簿中冻结的输入、划分、日程和基线集合。

4.3 通过恢复训练实现 WL 碰撞分离

WL 层级为训练恢复实验提供受控图对分层。BREC 提供 Basic、Regular、Extension、CFI、Four Vertex 和 Distance Regular 图对。对每个评估图对，IGSSE 接收无标签恢复训练，并在一致节点置换下解码两个嵌入。实验按分层报告重构 F1、AUC、AP，重构图分离和置换偏差。在恢复标准下，训练后的 IGSSE 通过准确重构和稳定分离，将被评估的二阶和三阶 WL 碰撞图对分开。

Web 关系任务。Amazon Photo、Coauthor CS 和 Cora 分别表示产品购买关系、学术协作和引文关系。IGSSE 在全部四个 Web 行中都是列出基线里最好的，包括 Photo interact 设置。Photo 和 Coauthor CS 上的增益较窄，这与强匹配基线一致；Cora 行的差距更大。该记录在匹配训练设置下报告 Web 任务效用。

跨语义压力测试。HiGraph、OCB 和 TimingPredict 改变图语义和输出粒度，AIDS 和 IMDB 增加分子条件和弱特征社会图条件。点接口和集合接口在每个设置中都可用，参数针对目标任务训练。这些测试测量架构在语义变化下的覆盖能力。

4.4 合法性引导自回归增长

生成实验使用图规则监督训练集合扩展，然后冻结参数，并在自由增长中移除逐步规则教师。结果工作簿在目标尺寸上报告终止有效性和 Emb F1 探针。Legal 和 Net 使用不同的 live state 选择规则，因此二者的有效性数值需要分开解释。

评估设置。训练阶段在训练规模上提供图规则合法性信号。评估阶段固定学习参数，提高目标尺寸，并在每个扩展步骤中使用学习参数。Legal 选择规则保留满足图规则谓词的状态，而 Net 选择规则使用学习到的网络分数选择 live states。记录保存目标尺寸、样本数、最大 live state 容量、选择规则和随机种子。这些细节通过分离学习转移、过滤规则、live state 容量和训练教师，标识终止有效性的来源。

平面图结果显示选择规则会改变终止有效性。弦图和二部图行把变化的图规则作为额外评估轴。结果支持相对于所列机制代理的合法性引导增长。分布保真证据仍需要度或聚类统计、适当的 MMD、唯一性、新颖性和节点顺序敏感性。

4.5 消融与证据边界

消融工作簿分离恢复损失、噪声、冻结表示和读出选择。Full 列来自主比较；变体来自共同消融套件。因此绝对数值不是主表的第二个实现。其方向性变化表明该套件把哪些组件归因于观察到的效用。

移除某个恢复项会在完整套件中降低任务效用、结构探针或二者。Frozen-$\Hset$ 在展示的 Photo 和 Cora 行中造成最大下降，而替换集合感知读出器也降低分数。这些消融在消融套件内支持组件归因，直接恢复表提供互补的重构证据。

4.6 可复现性、成本与限制

发布包提供预训练 checkpoint、端到端 toy test，以及 OCB、HiGraph 和 planar 元数据检查。链接训练把点对采样为稀疏关系目标。这描述了实现成本。提交前，我们会为每个主要图规则设置报告参数量、有效优化步数、墙钟时间、每次更新耗时、峰值内存和推理时间。

当前证据覆盖三个评估轴。第一，所有任务实例独立训练。第二，恢复目标覆盖目标链接和节点内容，边属性由显式边解码器和目标处理。第三，终止有效性与图规则谓词、live state 容量和选择规则一起报告。生成结果覆盖被测试的图规则。

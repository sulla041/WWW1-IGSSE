4 Experiments

实验部分通过四个结果视角评估 IGSSE。第一，特征预测主实验是核心比较，覆盖 Web 关系图、程序图、电路图、时序图、分子图和社会图。第二，自回归实验检验同一个点集对象是否可以用于规则引导的图扩展。第三，消融实验衡量内容恢复、关系恢复、结构偏差、训练扰动和集合读出对最终性能的贡献。第四，WL 碰撞实验研究经过恢复训练的点集是否能区分 BREC 与 WL 诊断集合中的受控非同构图对。四个实验共同检验任务效用、图增长、组件归因和受控结构分离。

4.1 Feature Prediction Main Experiment

主实验评估异质图任务上的监督预测。Amazon Photo、Coauthor CS 和 Cora 分别表示产品共同购买、学术协作和引文网络。HiGraph 评估用于恶意软件分类的层次程序控制流图。OCB 与 TimingPredict 评估模拟电路性能和布线前时序预测。AIDS 与 IMDB 评估标准图学习基准中的分子图和社会图分类。这些任务覆盖节点标签、图标签和连续图属性，因此可以检验学习到的点集在不同下游读出形式下的有效性。

基线覆盖只使用属性的预测、邻域聚合、传播、长程图序列建模和图到点集建模。MLP 只使用属性，不输入关系。GCN、GraphSAGE、GAT 和 GIN 代表常用邻域计算机制。APPNP 在预测后加入 personalized PageRank 传播。Graph Mamba 通过选择性状态空间建模图上的长程依赖。PST 将图映射为点集表示。表 1 来自实验结果_表A_表B.xlsx 的表甲，报告每个方法的 Emb 与 Result，并把两者拆成相邻两格。十个比较行中，IGSSE 在最终任务结果上均取得最优，说明可恢复点集可以作为有效的监督表示。

表 1：特征预测主实验结果。每个方法以 Emb 和 Result 两个单独单元格报告，小数保留两位。数据集包括 HiGraph IID、OCB Ckt-Bench-101、TimingPredict、Amazon Photo、Coauthor CS、Amazon Photo interact、Cora、AIDS、IMDB-MULTI 和 IMDB-BINARY。比较方法包括 MLP、GCN、GraphSAGE、GAT、GIN、APPNP、SGFormer、Polynormer、Graph-Mamba、PST 和 IGSSE。IGSSE 在十个最终任务结果中均为最优。

4.2 Autoregressive Graph Modeling

自回归实验在预测所用的同一集合表示上评估图扩展。rollout 时，集合扩展模块加入新的 live points，关系解码器把更新后的点集恢复为图，合法性信号选择满足目标规则的状态。三个规则检验互补的结构要求：平面图有效性对应全局可嵌入约束，弦图有效性对应所需环结构，二部图有效性对应二分关系约束。

比较方法包括循环式、注意力式、流式、score based 和 diffusion based 图生成方法，例如 GraphRNN、GRAN、GraphAF、GDSS 和 DiGress。完整工作簿记录 Emb 和 Valid 两类指标。论文表格为了压缩版面，只在半栏表中保留终止有效性这个关键指标。IGSSE 在四个 rollout 设置上均取得最高终止有效性，支持将点集扩展作为图增长接口。

表 2：自回归图建模结果。表格使用半栏，只保留 Valid 指标。任务包括 Planar Legal、Planar Net、Chordal 和 Bipartite。表中比较 best baseline 与 IGSSE，小数保留两位。IGSSE 在四个任务的 Valid 指标上均为最优。

4.3 Ablation Experiment

消融实验解释 IGSSE 的主要组件如何贡献性能。完整模型结合内容坐标、结构偏差坐标、特征恢复、关系恢复、训练扰动和集合读出。每个变体移除一个部分或替换读出器，同时保持与主表相同的数据集行和指标。消融用于判断点集的任务价值来自可恢复内容、可恢复关系、关系条件化偏差、可训练适配还是集合级聚合。

表 3 来自实验结果_消融_表A格式.xlsx，使用与主实验相同的 Emb 与 Result 两格分开的格式。移除特征恢复或关系恢复会削弱许多下游结果，说明近似等价依赖节点内容和点对关系同时保留。移除结构偏差项会在多个图任务上显著改变点几何；冻结点集会降低表示适配监督目标的能力。读出器替换主要影响图级任务行，这与集合聚合在图预测中的作用一致。

表 3：消融结果。每个变体以 Emb 与 Result 两个单独单元格报告，小数保留两位。列包括 Full、去掉特征恢复损失、去掉结构偏差项、去掉关系恢复损失、去掉 embedding 辅助项、freeze-H、mean-pool 和 point-MLP。行与主实验表甲一致。

4.4 WL Collision Experiment

WL 碰撞实验在受控非同构图对上评估结构分离。Weisfeiler Leman 层级为颜色细化和高阶图区分提供标准参照。BREC 提供用于暴露图神经网络实现表达性的图对。对每个图对，IGSSE 用恢复目标训练嵌入和关系解码器，然后在一致节点置换后比较重构图是否仍保持非同构。

表 4 来自实验结果_表A_表B.xlsx 的 BREC 扩展 160 对 sheet，并使用半栏形式只保留碰撞率这个关键指标。Basic 与 Extension 中全部覆盖图对均通过直接图恢复，并且碰撞率为零。覆盖集合包含 160 个官方非同构图对，这些图对属于二维 WL 碰撞情形，训练后的重构图保持分离。较小的 60 对诊断也呈现相同趋势：Basic 十对、Extension 十对、Regular 三对通过恢复，通过恢复的 23 对碰撞率为零。WL 实验说明，经过恢复训练的点集可以通过准确图重构解决已覆盖的 WL 碰撞案例。

表 4：WL 碰撞结果。表格来自 BREC expanded 160-pair workbook sheet。表格使用半栏，只保留 covered pairs 和 collision rate。Basic 60 对与 Extension 100 对均通过恢复并保持零碰撞率。

四个实验构成紧凑的证据链。主实验显示下游任务效用，自回归实验显示同一表示上的图增长，消融实验归因可恢复集合构造的作用，WL 实验显示恢复后的点集能够区分已覆盖的非同构碰撞图对。

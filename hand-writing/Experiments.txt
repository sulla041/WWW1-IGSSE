4 Experiments

实验部分通过四个互补设定评估 IGSSE。特征预测主实验测量 Web 关系、程序、电路、时序、分子和社会数据上的监督效用。自回归实验在同一个点集上进行规则引导的图扩展。消融实验逐项移除训练或读出组件。WL 碰撞实验在 BREC 与 WL 诊断集合的受控非同构图对上评价结构分离。四个设定共同连接下游预测、图增长、组件贡献和结构分离。

4.1 Feature Prediction Main Experiment

主实验在三类任务设定下评估监督预测。Amazon Photo、Coauthor CS 和 Cora 对应产品共同购买、学术协作和引文网络上的节点分类。HiGraph 对应恶意软件分类的程序控制流图。OCB 与 TimingPredict 对应模拟电路性能和布线前时序预测。AIDS、IMDB-M 和 IMDB-B 对应分子图与社会图分类。每个数据集中的方法使用相同节点属性、观测关系、数据划分和预测头。

基线覆盖邻域计算、传播、长程序列建模和图到点集建模。GCN、GraphSAGE、GAT 和 GIN 使用标准邻域聚合；APPNP 加入 personalized PageRank 传播；SGFormer 与 Polynormer 提供全局传播机制；Graph Mamba 使用选择性状态空间建模长程图依赖；PST 将图映射为点集。表 1 报告每个方法的 Emb 与 Result，并把两者拆成相邻两格。Emb 是嵌入得分，Result 是最终任务指标；Metric 列给出 F1、相关系数、决定系数或准确率。节点分类从点预测训练 mask 中的节点标签，图分类从池化点集预测图标签，电路和时序任务输出图级连续值并使用回归损失。IGSSE 在十个比较行的 Result 和 Emb 上均达到最优，说明该点集能够稳定服务于下游预测。

表 1：跨程序、电路、时序、Web、分子和社会图任务的特征预测结果。每个方法以 Emb 和 Result 两个单独单元格报告，小数保留两位。数据集包括 HiGraph IID、OCB Ckt-Bench-101、TimingPredict、Amazon Photo、Coauthor CS、Amazon Photo interact、Cora、AIDS、IMDB-MULTI 和 IMDB-BINARY。比较方法包括 GCN、GraphSAGE、GAT、GIN、APPNP、SGFormer、Polynormer、Graph-Mamba、PST 和 IGSSE。Emb 表示嵌入得分，Result 表示最终任务性能；表内数据集和 baseline 名称均加入引用，粗体表示每行最大值。

4.2 Autoregressive Graph Modeling

自回归实验在预测所用的同一点集上进行四种规则引导的 rollout。每一步由集合扩展算子提出新点，点对关系解码器确定图关系，规则评价器判断终止图是否满足约束。Planar Legal 与 Planar Net 指定平面图有效性，Chordal 指定弦结构，Bipartite 指定二分关系约束。这些任务检验点增加和关系形成在连续图增长中的一致性。

比较方法包括 GraphRNN、GRAN、SPECTRE、BiGG、EDGE 和 GDSS，分别覆盖循环式、注意力式、流式、边生成式和 score based 图生成方法。GraphAF 与 DiGress 纳入完整评价，表格因单栏布局省略。Emb 表示 rollout 关联的嵌入结果，Valid 表示满足指定图规则的终止 rollout 比例。每次 rollout 从规定初始状态开始，反复提出新点，直到达到目标规模或选择器输出终止状态；Valid 只统计终止图，中间候选不计入成功样本。IGSSE 在 Planar Legal、Planar Net、Chordal 和 Bipartite 上均取得最高 Valid，说明同一点集接口能够支持规则引导的图扩展。

4.3 Ablation Experiment

消融实验隔离构造和使用点集的主要组件。完整模型包含内容坐标、全局结构偏差、特征恢复损失、关系恢复损失、embedding 辅助项和可训练集合读出。各变体逐项移除一个损失或冻结点集，同时固定数据集、划分、优化器 schedule 和预测头，从而形成受控的组件比较。

表 3 只保留最终 Result 指标。四个损失消融列分别表示移除特征恢复、结构偏差、关系恢复和 embedding 辅助项，freeze 表示下游优化时固定点集。消融指令是保持任务头和训练 schedule 不变，每次只改变一个表示组件。Metric 列保留各数据集原始任务指标，包括 F1、相关系数、决定系数和准确率。完整模型在列出的 HiGraph、OCB、Timing、Photo、Coauthor、Photo interaction、Cora、AIDS 和 IMDB-B 行取得最高 Result，并在 IMDB-M 行达到并列最优，说明完整的内容、结构、恢复和集合读出流程是有效配置。

4.4 WL Collision Experiment

WL 碰撞实验在受控非同构图对上评估结构分离。Weisfeiler Leman 层级提供颜色细化参照，BREC 提供用于表达性评价的 Basic、Regular、Extension、Vertex 和 Distance 诊断设定。每个图对分别形成点集并通过关系解码器得到重构图，再在一致节点置换下比较邻接关系。

WL 碰撞实验在受控非同构图对上评价结构分离。Weisfeiler Leman 层级提供颜色细化参照，BREC 提供用于表达性评价的 Basic、Regular、Extension、Vertex 和 Distance 诊断设定。每个图对独立形成点集并通过关系解码器得到重构图，再在一致节点置换下比较邻接关系。

该实验的任务指令是图对分离：两个输入图分别处理，重构图进行比较；非同构图对在恢复后变得不可区分时计为碰撞。表 4 将 BREC 数据集横向列举，第二行只保留 Collision rate，表示恢复后发生碰撞的图对比例。

IGSSE 在表中所有 BREC 设定上取得零 Collision rate。扩展工作簿中的 Basic 与 Extension 覆盖图对保持零碰撞率，较小诊断中通过恢复的图对也保持零碰撞率，说明恢复训练后的点集能够分离所评估的 WL 碰撞图对。

表 4：点集图重构后的 BREC 诊断类别碰撞率。数据集横向列举，第二行给出 Collision rate，表示评价非同构图对发生碰撞的比例；表内 BREC 类别均加入引用。Basic 与 Extension 保持零碰撞率，其余数据集按当前评价结果保留为未报告状态。

四个实验构成紧凑的证据链。主实验显示下游任务效用，自回归实验显示同一表示上的图增长，消融实验归因可恢复集合构造的作用，WL 实验显示恢复后的点集能够区分已覆盖的非同构碰撞图对。
